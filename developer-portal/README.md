# SAHOOL Developer Platform

Phase 12 adds a partner ecosystem surface:

- Plugin manifests and sandbox policy
- Marketplace app registration and installation
- Webhook subscriptions with HMAC signatures
- Connector descriptors for ERP/equipment/weather/satellite/IoT
- SDK manifests for Python, TypeScript, and Flutter
- Usage metering and quota enforcement

All runtime actions remain tenant-scoped and fail-closed for sensitive permissions.
