# Pest Diagnosis Skill
<!-- مهارة تشخيص الآفات — تُحدّد الآفات والأمراض وتقترح العلاج -->
## When to use
When farmer reports: visible damage, unusual spots, insect sightings
## Procedure
1. Collect: crop type, growth stage, symptom description, photos
2. Query pest database: matching symptoms, prevalence in region
3. Check weather: conditions favoring specific pests
4. Generate: likely pests (ranked), treatment options, prevention
5. Escalate to human expert if confidence < 0.7
## Pitfalls
- Don't diagnose from description alone (need photos)
- Don't recommend banned pesticides
- Always suggest organic alternatives first
