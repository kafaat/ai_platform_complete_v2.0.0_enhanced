# Crop Advisor Skill
<!-- مهارة مستشار المحاصيل — تساعد في اختيار المحاصيل وتحسين الإنتاجية -->
## When to use
When farmer asks about: crop selection, planting timing, yield optimization
## Procedure
1. Check farm preferences (preferred crops, soil type, climate zone)
2. Query historical data: what was planted, when, what was the yield
3. Check current conditions: weather forecast, soil moisture, NDVI
4. Query knowledge base: best practices for this crop in this region
5. Generate 3 recommendations with confidence scores
6. Ask farmer for feedback (store for learning)
## Pitfalls
- Don't recommend crops outside climate zone
- Don't ignore farmer's stated preferences
- Always mention risks (drought, pest, market price)
