# Irrigation Skill
<!-- مهارة الري — تُحسّن جدولة الري وتوفير المياه -->
## When to use
When farmer asks about: irrigation schedule, water optimization, drought response
## Procedure
1. Check current soil moisture from sensors
2. Check weather forecast (rain expected?)
3. Check crop growth stage (water needs vary)
4. Query irrigation history (adherence, effectiveness)
5. Calculate optimal schedule using ET0 formula
6. Generate schedule with justification
## Pitfalls
- Don't over-irrigate (root rot risk)
- Account for irrigation method (drip vs flood)
- Consider electricity/solar availability
