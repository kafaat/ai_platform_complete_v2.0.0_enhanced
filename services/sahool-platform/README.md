# SAHOOL Platform — منصة زراعية وطنية قابلة للتوسّع

**ليست تطبيق مزرعة — بل منصة لليمن والوطن العربي.**

البنية تفصل ثلاث طبقات فصلاً صارماً:

```
core/      → الفيزياء والفسيولوجيا. لا تعرف اليمن، ولا الجوف، ولا أي مزرعة.
districts/  → معايرة كل مديرية مناخي (تُعاير على ≥5 مزارع — عتبة قابلة للتعديل).
tenants/   → مزارع حقيقية. آلاف المستأجرين. كل بياناتهم الخاصة هنا فقط.
```

## القاعدة الذهبية المعمارية

> **النواة لا تعرف شبراً من أرض الواقع.** تعرف فقط القوانين (FAO-56، WOFOST،
> عتبات الملوحة، Q10). كل رقم خاص بمزرعة (الغلة، عمق البئر، تكلفة، اسم الصنف)
> يعيش في `tenants/`. كل معايرة محلية تعيش في `districts/`.

اختبر هذا: `grep -rE "(sakha|6.17|142ha|W[1-8])" core/` يجب أن يعود **فارغاً**.

## الطبقات الثلاث بالتفصيل

### `core/` — الفيزياء (محايدة الموقع)
- `engines/fao56.py` — ET₀, Kc, ETc, Ks, الغسيل (مدخلات: طقس + بطاقة محصول)
- `engines/suitability.py` — حاكمات + Fuzzy (مدخلات: تربة + محصول)
- `engines/fusion.py` — دمج المؤشرات (تباين واعٍ بالارتباط)
- `engines/water_cost.py` — تكلفة الضخ (نطاق، حسب العمق والطاقة)
- `engines/fertility.py` — السماد (معادلة الفرق) + Q10 للمعدنية
- `engines/market_analyzer.py` — CV + فجوة السوق
- `provenance.py` — تتبّع النسب + القاعدة الذهبية (الثقة = أضعف حلقة)
- `crop_cards/*.yaml` — Kc + حاكمات عامة. **بلا معايرة، بلا غلة.**
- `observation_matrix.yaml` — 62 مرصداً، 10 مجموعات (المصدر الوحيد للحقيقة)

### `districts/<region>/` — المعايرة المديريةية
- `climate.yaml` — zone_factor (مُخرج معايرة، null حتى تكتمل 5 مزارع)
- `soil.yaml` — نطاقات EC/pH/SAR السائدة
- المعايرة تتبع **الأساليب العلمية المعتمدة**، توثّق المصدر، لا تخترع طريقة.

### `tenants/<id>/` — المزرعة الحقيقية
- `farm_map.yaml` — المناطق، المحاصيل، الري
- `well_specs.yaml` — الآبار (أعماق، طاقة)
- `yield_history.csv` — **مصدر الحقيقة الأعلى** (الغلة الموزونة الفعلية)
- `economics.yaml` — تكاليف المالك (لا أرقام مخترعة)

## طبقات المتانة (Resilience)

- `sensor_health.yaml` — صحة كل حساس (آخر معايرة، عتبة إيقاف)
- `fallback.yaml` — سيناريوهات السقوط (Graceful Degradation) + حاكمات بلا سقوط
- `validate_observations.py` — بوابة ما قبل التوصية: تحسب درجة الجودة وتمنع
  التوصيات العمياء (حاكم صارم غائب = BLOCKED)

## درجة الجودة (شهادة ميلاد كل توصية)

```
HIGH    → كل الفئة A متوفرة، ≤3 ناقص من B
MEDIUM  → كل A متوفرة، >3 ناقص من B
LOW     → ناقص من A (غير حاكم صارم)
BLOCKED → حاكم صارم غائب (S3/S4/I3/O1/O2/L3) → لا توصية
```

الفئة A (العمود الفقري، 10): C1, C5, S3, S4, I1, I3, O1, O2, G1, L3

## المعايرة والتوسّع

- **المعايرة:** تتبع الأساليب المعتمدة (WOFOST قياسي، conformal، سُلّم النماذج
  LASSO→XGBoost→RF حسب حجم العينة). توثّق الأسلوب والمصدر.
- **التدرّج:** تقدير الفريق — لا ترتيب إجباري مُبرمَج. أي مديرية يبدأ متى يقرّر
  الفريق. عتبة "5 مزارع" قابلة للتعديل.
- **النواة جاهزة لكل اليمن والعرب الآن** (فيزياء عامة). كل مديرية يُعاير حين
  تتوفر مزارعه.

## تشغيل سريع

```bash
python validate_observations.py tenants/001-aljawf-142ha
# يُظهر شهادة الجودة — حالياً BLOCKED لأن تحاليل تربة الجوف لم تُدخل بعد
```

## الحالة الراهنة

النواة جاهزة (فيزياء). الجوف (tenant 001) مُسجّل بحقائقه البنيوية + 3 مواسم غلة
فعلية. المعايرة المديريةية للجوف **قيد الانتظار** (1 من 5 مزارع). لا أرقام وهمية.
