# دستور بناء المعلومة — SAHOOL Information Provenance
## كيف تُبنى كل معلومة: من المُدخل الخام إلى التوصية

> **المبدأ الحاكم:** لا توصية بلا سلسلة نسب (provenance chain) كاملة.
> كل رقم يجب أن يجيب: من أين جاء؟ ما مصدر حقيقته؟ ما نسبة خطئه؟ كيف يُتحقق منه؟

---

## ٠. المصطلحات الأساسية (Definitions)

| المصطلح | التعريف |
|---------|---------|
| **المُدخل الخام (Raw Input)** | قياس مباشر من المصدر (حساس، قمر، مختبر) قبل أي معالجة |
| **مصدر الحقيقة (Ground Truth)** | القياس المرجعي الذي يُعاير عليه كل شيء (تحليل مخبري، حصاد موزون) |
| **نسبة الخطأ (Error Margin)** | عدم اليقين في القياس، يُورَّث ويتراكم عبر المراحل |
| **المعايرة (Calibration)** | ربط نموذج/قمر ببيانات أرضية حقيقية |
| **الثقة (Confidence)** | فئة (عالية/متوسطة/منخفضة) محكومة بأضعف حلقة في السلسلة |
| **حاكم (Governing)** | عامل يُلغي القرار إن فشل (knock-out) |
| **مُعدِّل (Modifying)** | عامل يخفّض الجودة لكن لا يُلغي (treatable) |

---

## ١. التصنيف الأساسي للمعلومات (4 طبقات)

```
الطبقة          المصدر                      الثبات         مثال
─────────────────────────────────────────────────────────────────
خام (Raw)       حساس/قمر/مختبر مباشر         لحظي           NDVI=0.6
مشتق (Derived)  معادلة على الخام             محسوب          ETc=6.5mm
مُركّب (Fused)   دمج عدة مصادر                موزون          health_score
قرار (Decision) قواعد + معايرة على المُركّب   مُفسَّر         "ازرع سورغم"
```

كل طبقة ترث خطأ الطبقة تحتها. **القرار لا يكون أوثق من أضعف مُدخل فيه.**

## ٢. مخطط التدفق العام (Master Flow)

```
┌─────────────────────────────────────────────────────────────┐
│ المرحلة ١: المُدخلات الخام (Raw Inputs)                       │
│   كل مُدخل يحمل: القيمة + المصدر + نسبة الخطأ + التاريخ        │
└──────────────────────────┬──────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│ المرحلة ٢: فحص الجودة (Quality Gate)                          │
│   • غطاء سحب < ١٠٪؟  • ٣ قراءات لا واحدة؟                     │
│   • الحساس مُعاير؟   • التاريخ حديث؟                          │
│   فاشل → يُرفض المُدخل أو يُخفَّض وزنه                          │
└──────────────────────────┬──────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│ المرحلة ٣: الاشتقاق (Derivation — معادلات راسخة)             │
│   FAO-56، WOFOST، Q10... كل معادلة بمصدرها                    │
│   الخطأ يُورَّث: σ_out = f(σ_in)                              │
└──────────────────────────┬──────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│ المرحلة ٤: الدمج (Fusion — واعٍ بالارتباط)                   │
│   σ²_fused = Σwᵢ²σᵢ² + 2Σ wᵢwⱼ ρᵢⱼ σᵢσⱼ                      │
│   الفائدة من دمج العائلات المستقلة (بصري+SAR+حراري)           │
└──────────────────────────┬──────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│ المرحلة ٥: المعايرة المحلية (Calibration)                    │
│   ربط النموذج ببيانات الجوف الفعلية (Ground Truth)           │
│   قبلها: "قيد المعايرة" — لا رقم وهمي                         │
└──────────────────────────┬──────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│ المرحلة ٦: القرار (Decision — بوابات متسلسلة)               │
│   حاكم (يُقصي) → موسمي → إنتاجي → سوقي (يرتّب)               │
└──────────────────────────┬──────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│ المرحلة ٧: التفسير + الثقة (Explanation + UQ)               │
│   توصية + سبب + نطاق (لا نقطة) + فئة ثقة + المصادر           │
└─────────────────────────────────────────────────────────────┘
```

| SAVI | S2 B8/B4/L | مصحح تربة | ±0.04 | LAI + غطاء أرضي | 5 أيام |

## ٤. مخططات تدفق تفصيلية لكل معلومة

### ٤.١ الاحتياج المائي (Water Requirement)

```
المُدخل الخام                المعادلة (المصدر)              المُخرج
──────────────────────────────────────────────────────────────────
حرارة، رطوبة، رياح، إشعاع  ─→ Penman-Monteith            ─→ ET₀
  (محطة، ±2-3°م)              (FAO-56 Eq.6)                  (mm/يوم)
                                    ↓
نوع المحصول + عمره         ─→ منحنى Kc حسب المرحلة        ─→ Kc
  (سجل + بطاقة)              (FAO-56 Table 11/12)           (ثابت)
                                    ↓
                            ETc = ET₀ × Kc                ─→ ETc
                                    ↓
نسيج التربة (مختبر)        ─→ معامل التبخّر السطحي Ke      ─→ ETc_zone
  (±3٪)                      (FAO-56 Table 19)
                                    ↓
EC التربة (حساس/مختبر)     ─→ Ks الإجهاد الملحي           ─→ ETc_adj
  (±2-10٪)                   (FAO-56 Eq.81, Maas-Hoffman)
                                    ↓
المطر الفعّال (محطة)        ─→ ETc_adj − المطر            ─→ صافي الري
                                    ↓
EC الماء + كفاءة الري      ─→ + الغسيل ÷ الكفاءة          ─→ الري النهائي
  (±5-10٪)                   (FAO-56 Eq.82)                 (م³/هكتار)

نسبة الخطأ النهائية: ±10-15٪ (تراكم أخطاء المُدخلات)
مصدر الحقيقة: حساس رطوبة التربة + استهلاك العدّاد الفعلي
التحقق: قارن الري المحسوب بالاستهلاك الفعلي عبر الموسم
```

### ٤.٢ تشخيص الملوحة (Salinity Diagnosis)

```
المُدخل الخام                المنطق                        المُخرج
──────────────────────────────────────────────────────────────────
EC (حساس + مختبر)          ─→ مقدار الملوحة              ─→ شدّة
  (±2-10٪)                                                 (dS/m)
                                    +
pH (مختبر، ±0.1)           ─→ شجرة التشخيص:              ─→ النوع
SAR/الصوديوم (مختبر، ±5٪)     EC↑ + pH>8.5 + Na↑ = صودية    (مالحة/
                              EC↑ + pH طبيعي = مالحة         صودية)
                                    +
SI من القمر (±0.1)         ─→ الامتداد المكاني           ─→ خريطة
SAR رادار (RSMI، r=0.85)     (تأكيد + توزيع)                المناطق
                                    ↓
                            البروتوكول (FAO-56 Ch.8):
                            مالحة → غسيل + أصناف متحملة
                            صودية → جبس ٥٠٪ + جير + صرف

مصدر الحقيقة: EC مخبري من عينات متعددة الأعماق
التحقق: إعادة قياس EC بعد الغسيل
```

### ٤.٣ ملاءمة المحصول (Crop Suitability)

```
المُدخل                      البوابة                       المُخرج
──────────────────────────────────────────────────────────────────
pH, EC, الحرارة، البرودة   ─→ البوابة ١: حاكمة            ─→ يمر/يُقصى
  (مختبر ±0.1, ±2٪)           (knock-out — إن فشل = N)       (N أو متابعة)
                                    ↓ (الناجون)
توقيت الإزهار + الحرارة     ─→ البوابة ٢: موسمية          ─→ يمر/يُقصى
  (GDD، توقّع طقس)            (إزهار في حرارة آمنة؟)
                                    ↓
OM, NPK (مُعدِّلات)         ─→ Fuzzy trapezoidal          ─→ درجة
  (مختبر ±5٪)                 (مع منطقة ميتة)               (S1/S2/S3)
                                    ↓
WOFOST + تاريخ الجوف       ─→ البوابة ٣: إنتاجية         ─→ ترتيب
  (مُعاير)                    (كم طن متوقع؟)
                                    ↓
سعر + فجوة (CV)            ─→ البوابة ٤: سوقية           ─→ ترتيب نهائي
  (بيانات سوق)                (ربحية + فجوة)

مصدر الحقيقة: معايير FAO + معايرة بإنتاج الجوف الفعلي
الثقة: محكومة بأضعف مُدخل (إن NPK حساس ±25٪ → ثقة منخفضة)
```

### ٤.٤ تقدير الإنتاج (Yield — مع المعايرة)

```
الحالة ١: قبل المعايرة (الآن)
  WOFOST (فيزياء) ─→ تقدير أولي ─→ ⚠️ "قيد المعايرة" (لا رقم معروض)

الحالة ٢: بعد جمع بيانات الحصاد (Phase 0b)
  بيانات حصاد فعلية (Ground Truth)
       ↓
  معايرة WOFOST (ضبط RUE, GDD على الواقع)
       ↓
  حساب البواقي على مجموعة محجوبة (held-out)
       ↓
  Conformal Prediction ─→ نطاق [أدنى, أعلى] بتغطية ٩٠٪
       ↓
  المُخرج: "٤.٢ – ٧.١ طن/هكتار" (نطاق، لا نقطة وهمية)

مصدر الحقيقة: الحصاد الموزون الفعلي (±2-5٪) — الأعلى في النظام
التحقق: MAPE على حقول/مواسم محجوبة (هدف < ٣٠٪)
شرط: لا BiLSTM قبل ٥٠٠+ نقطة متنوّعة جغرافياً
```

## ٥. قواعد وراثة الخطأ (Error Propagation Rules)

```
١. الضرب/القسمة:  الأخطاء النسبية تُجمع تربيعياً
   z = x·y  →  (σz/z)² = (σx/x)² + (σy/y)²

٢. الجمع/الطرح:   الأخطاء المطلقة تُجمع تربيعياً
   z = x+y  →  σz² = σx² + σy²

٣. الدمج الموزون: واعٍ بالارتباط
   σ²_fused = Σwᵢ²σᵢ² + 2Σ wᵢwⱼ ρᵢⱼ σᵢσⱼ
   (المُدخلات المترابطة لا تقلّل الخطأ — العائلات المستقلة تقلّله)

٤. القاعدة الذهبية: الثقة النهائية = أضعف حلقة
   إن اعتمد القرار على حساس NPK (±25٪) → التوصية "تقديرية"
```

## ٦. تقليل الخطأ (Error Reduction Strategy)

```
١. القياس المتعدد:    ٣ عينات بدل واحدة → متوسط أدق
٢. المعايرة:          حساس رخيص + تحليل مخبري دوري → تصحيح الانحراف
٣. الدمج:             عدة مصادر للمتغير نفسه (رطوبة: NDWI+حساس+SAR)
٤. التحقق التاريخي:   بيانات الجوف الفعلية → القيم الواقعية لأرضك
٥. المجال لا الرقم:   "EC بين ٤-٥" أصدق من "EC = ٤.٥" القاطع
```

## ٧. مستويات جمع البيانات (Tiered Collection — للواقع اليمني)

```
Tier 1 (إلزامي، رخيص):  pH strip + EC meter (~$50) + سجل يدوي
                         → النظام يعمل بهذا الحد الأدنى
Tier 2 (موصى):           تحليل مخبري كامل (إن توفّر مختبر)
                         → دقة أعلى، معايرة الحساسات
Tier 3 (مثالي):          LAI meter + TDR + حصاد موزون
                         → معايرة WOFOST كاملة

النظام يبدأ بـ Tier 1، يتحسّن مع 2/3. لا ينتظر المثالي.
```

## ٨. الحالة الراهنة لكل معلومة (Provenance Status)

| المعلومة | الحالة | السبب |
|----------|--------|-------|
| ET₀ / الاحتياج المائي | ✅ جاهز | فيزياء FAO-56، لا تحتاج معايرة |
| تشخيص الملوحة | ✅ جاهز | عتبات FAO راسخة |
| ملاءمة المحصول | ✅ جاهز | معايير FAO + Fuzzy |
| تكلفة الماء | ✅ جاهز | فيزياء الضخ (نطاق) |
| الخصوبة/السماد | ✅ جاهز | معادلة الفرق + Q10 |
| **تقدير الإنتاج** | ⏳ قيد المعايرة | ينتظر حصاد الجوف الفعلي |
| السوق | ⚠️ محدود | بيانات أسعار اليمن شحيحة (CV فقط) |
| كشف الأمراض | ⏳ ينتظر بيانات | صور يمنية موسومة غير موجودة |

---

> **الخلاصة:** كل معلومة في SAHOOL تُبنى عبر سبع مراحل موثّقة، من المُدخل
> الخام إلى التوصية، بمصدر معروف ونسبة خطأ متتبَّعة وثقة محكومة بأضعف حلقة.
> ما لا يُعاير بعد = "قيد المعايرة"، لا رقم وهمي. مصدر الحقيقة الأعلى دائماً
> = القياس الميداني الفعلي (الحصاد الموزون، التحليل المخبري).
