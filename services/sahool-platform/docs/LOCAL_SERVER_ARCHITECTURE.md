# معمارية السيرفر المحلي — SAHOOL Local Server (GPU)

> السيرفر المحلي المزوّد بـ GPU (فئة 50/90) هو حيث يحدث الاتصال الفعلي
> بالمصادر الخارجية والمعالجة الثقيلة. المنصة (core) محايدة؛ السيرفر يشغّلها.

## لماذا سيرفر محلي؟ (السياق اليمني)

```
✅ سيادة البيانات: بيانات المزارعين تبقى محلياً (مبدأ FAO + DATA_GOVERNANCE)
✅ شبكة ضعيفة: المعالجة محلياً، لا تعتمد على سحابة بعيدة
✅ تكلفة: لا فواتير سحابية متكرّرة
✅ offline-first: الموبايل يزامن مع السيرفر المحلي عند توفّر الشبكة
```

## أين يُستخدم الـ GPU؟ (صدق تقني)

```
يستفيد من GPU فعلاً:
  ✅ معالجة الـ raster (NDVI/SI لملايين البكسلات)
  ✅ كشف الأمراض (YOLO على صور الحقل) — عند توفّر بيانات موسومة
  ✅ النماذج العميقة (BiLSTM) — عند 500+ نقطة (سُلّم النماذج)

لا يحتاج GPU (يعمل على CPU):
  • FAO-56، suitability، المعايرة (حسابات خفيفة)
  • المايسترو، الموصّلات، كشف مناطق الاهتمام

→ GPU استثمار للمرحلة المكانية (الصور) والرؤية الحاسوبية،
  لا للحسابات الفيزيائية الخفيفة.
```

## المصادر الخارجية الموصولة

| المصدر | الموصّل | يجلب | المفتاح | الخطأ |
|--------|---------|------|---------|-------|
| **Open-Meteo** | weather_openmeteo | طقس (C1-C5) لـ FAO-56 | لا (مجاني) | ±2-3% |
| **Copernicus CDSE** | copernicus | NDVI/SI/SAR (R1,R5,R6) | بيئة | ±0.05-0.10 |

### مبادئ الموصّلات (أفضل الممارسات)
- لا مفاتيح بالكود — من متغيّرات البيئة فقط (`CDSE_CLIENT_ID/SECRET`).
- لا اختراع بيانات — بلا اتصال = حالة `UNAVAILABLE` صريحة.
- كل نتيجة تحمل مصدرها ونسبة خطئها (دستور المعلومة).
- Fallback عند فشل المصدر — لا انهيار.

## خط أنابيب الصور (المراحل الست)

```
١. الجلب     CDSE، كل 3-5 أيام (مرور القمر)
٢. القص      AOI الحقل فقط (لا Granule كامل — توفير)
٣. السحب     C6: >20% → S1 رادار أو دمج S1+S2 (fusion.py)
٤. الحساب    NDVI/SI لكل بكسل (GPU) → raster
٥. التخزين   GeoTIFF + PNG overlay + thumbnail
٦. Timeline  تواريخ + صور مصغّرة + كشف التغيّر الزمني
```

## التصحيح الصادق: "مؤشر التربة من القمر"

```
القمر يعطي:    SI (مؤشر ملوحة سطحي من الانعكاس الطيفي) — استرشادي ±0.1
لا يعطي:       EC التربة المخبري (S3 الحاكم)
الدور الصحيح:  SI يوجّه أين تأخذ عينة S3، لا يحلّ محلّها
```

نفس المبدأ الحاكم: الاستشعار يوجّه، المختبر يحكم. القمر يكشف البقعة
المشبوهة بصرياً؛ التحليل المخبري يؤكّد ويقيس.

## النشر (Deployment)

```
المرحلة الحالية:  المنطق يعمل بـ CPU + SQLite (مُختبَر)
عند تجهيز السيرفر:
  1. متغيّرات البيئة (CDSE keys)
  2. تثبيت rasterio/GDAL (معالجة GeoTIFF)
  3. توصيل الموصّلات بالشبكة (requests/httpx)
  4. (اختياري) PostGIS عند تجاوز ~100 مزرعة
  5. خدمة الموبايل (مزامنة offline-first)
```

> **القاعدة الذهبية تبقى:** السيرفر يجلب ويعالج، لكن الحاكمات الصارمة
> (التربة المخبرية) تبقى مصدر الحقيقة. القمر والطقس يوجّهان ويُثريان،
> لا يحكمان. لا توصية بلا بيانات حقيقية ترفع BLOCKED.
