# تجربة Impeccable لمراجعة واجهات سهول — فحص ظلي غير مانع

هذه تجربة مراجعة ساكنة لأربعة ملفات TSX **موجودة أصلًا في `main`**، وليست تعديلًا لتصميم سهول أو إضافة حزمة npm إلى تطبيقها. نقرأ الملفات فقط ونشغّل كاشف `Impeccable 4.8.0` داخل Docker مؤقت بلا شبكة، بمستخدم غير جذري، وبصلاحيات وموارد مقيدة.

| نطاق المنتج | الملف المفحوص |
|---|---|
| Field Management | `frontend/src/sections/FieldWorkspaceRouteShell.tsx` |
| MapHub | `frontend/src/sections/MapHub.tsx` |
| Irrigation | `frontend/src/sections/IrrigationManualOperationsPanel.tsx` |
| Remote Sensing | `frontend/src/sections/FieldWorkspaceImageryPanel.tsx` |

الوظيفة `.github/workflows/ui-quality-shadow.yml` تثبت مصدر الأداة عند إصدار 4.8.0، وتمنع تشغيل `npm` lifecycle scripts، وتستخدم حاوية منفصلة تقرأ **ملفًا واحدًا فقط في كل فحص** بدل ربط كامل المستودع. لا تنفذ React أو Vite أو API الإنتاجية، ولا تصل إلى قواعد البيانات أو الاعتمادات. تحفظ النتائج و SHA256 وتقارن بايتات ملفات TSX الملاحظة مع Git Blob الفعلي لـHEAD.

تقبل البوابة رمز Impeccable `0` للصفر و`2` لوجود ملاحظات؛ كلاهما ينتج تقريرًا **للمراجعة فقط**. أما خطأ تشغيل الأداة أو JSON غير صالح أو اختلاف شفرة المصدر أو نقص أي ملف فيفشل بوابة الأدلة. يوجد فصل مقصود بين فشل تقنية القياس وبين أحكام الذوق؛ **لا تُعامل ملاحظات الأنماط وحدها كحاجز نشر**، ولا يُعلن تحقيق WCAG أو نجاح اختبارات التفاعل.

الاختبارات الحتمية:
```bash
python -m unittest discover -s experiments/ui-quality-shadow -p 'test_ui_quality_shadow.py' -v
```

لم تُدرج نتائج هذه التجربة في فحوص واجهة سهول الإنتاجية، ولم تُغيّر منطق العمليات الزراعية أو الحالة المحمية: MapHub يبدأ بالصورة الفضائية الخام/Truecolor، وأعمال الري اليدوية تبقى مرتبطة بالمجال والهوية، ولا تُستبدل المشاهد الجغرافية بنتائج وهمية.

**القبول المستقبلي المنفصل** يتطلب Playwright متصفّحًا على الواجهات الفعلية، واختبارات keyboard/focus/contrast على صفحات مصيّرة، وRTL والجوال، والتحقق من عدم تراجع خرائط MapHub وسير أعمال الري، ثم قرار صاحب النطاق. البوابة الحالية تقرير استكشافي وليس موافقة إنتاجية أو إثبات صلاحية تراخيص جميع التبعيات.
