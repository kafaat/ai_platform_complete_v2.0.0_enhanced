## كيف تُشغَّل؟ (يدويّاً الآن — grep)

لا أتمتة بعد (مهارة `/brain` مستقبليّة خارج النطاق). شغّل الفحوص من جذر المستودع:

```bash
# 1) الروابط الميتة: لكلّ [نص](مسار نسبيّ) تأكّد من وجود الهدف
grep -rhoE '\]\(([^)]+)\)' sahool-brain/ | sed -E 's/.*\(([^)]+)\)/\1/' \
  | grep -vE '^https?:' | while read -r p; do \
      t="${p%%#*}"; [ -z "$t" ] && continue; \
      ( cd sahool-brain && test -e "$t" ) || echo "DEAD: $p"; done

# 2) مجلّدات يتيمة (بلا ملفّ)
find sahool-brain -type d -empty
```
