# طبقة التكيّف مع الوكلاء والمنصات

## القاعدة

تظل جميع Skills `SKILL.md` مكتملة بذاتها. موقع التثبيت خاص بنسخة الأداة، ويجب التحقق منه من وثائقها الحالية. إن لم يدعم الوكيل تحميل Skills، استعمل `UNIVERSAL_WORK_START_AR.md` وأرفق نص المهارة المناسبة دون الادعاء بتثبيتها.

## وكلاء

- **Codex:** اقرأ تعليمات المنتج ومكان skills المدعوم في نسخته؛ احترم `AGENTS.md` وقواعد المشروع. لا تنقل الملفات تلقائياً إلى مجلدات لم توافق عليها المؤسسة.
- **Claude / Claude Code:** استخدم Skill عادية في الموقع المدعوم محلياً أو في الحساب؛ مسارات الحاوية المؤقتة لا تضمن الاحتفاظ.
- **Kimi Code CLI:** الوثائق الحالية توثق discovery من مسارات المشروع/المستخدم، وأمر `/skill:<name>`؛ تُستخرج التفاصيل من الوثائق الرسمية عند التثبيت.
- **OpenCode / أي وكيل آخر:** لا تفترض مساراً عاماً؛ Prompt نصي يبقى البديل القابل للنقل.

## منصات مستودعات

- **GitHub:** `concurrency` يغطي تشغيلات المستودع ضمن المجموعة المعنية، reusable workflows تقلل تكرار YAML. لا تفترض التزامناً عالمياً أو إتاحة Artifact Attestation لكل خطة.
- **GitLab:** `resource_group` للموارد الحساسة، و`needs` لمسارات DAG، و`rules:changes:compare_to` للاختيار، وJUnit **ليس** رمز خروج.
- **Gitee:** Gitee Go pipelines ومعرّفاتها وبوابات PR حسب السياسة. تحقق من صلاحيات الإدارة والاستثناءات.
- **GitCode:** مرجع لاكتشاف المشاريع، لكن تحقّق من upstream والنسخ المعكوسة وcommit/الترخيص قبل اعتماد أي مهارة.

## توزيع آمن

نوصي ببداية قراءة وتجربة محلية قبل تعديل `CLAUDE.md` أو `AGENTS.md` أو تفعيل أدوات إطلاق. اختَر مستودعاً مركزياً خاصاً فقط عند وجود إذن، واستخدم بصمات ZIP وفحصاً أمنياً للمواد التي ستوزع على الوكلاء.
