# Prompt — تسريع الاختبارات واستئنافها، يصلح لأي وكيل

حسّن استراتيجية الاختبارات في المهمة الحالية، مع **الحفاظ على جميع بوابات القبول الإلزامية** ودون افتراض إطار أو مشروع أو مزوّد سحابي معين. لا يعتبر هذا التوجيه تفويضاً بالدفع أو الدمج أو النشر أو الحذف أو تغيير الصلاحيات.

1. **اكتشف الواقع أولاً:** نوع Runner، الاختبارات المطلوبة، فحوص CI/الإصدار، تغيرات الشيفرة، اختبارات القواعد والاعتماديات المشتركة، حجم الموارد المتاح فعلياً والعمليات الأخرى النشطة. اقرأ ملفات الاستئناف بوصفها بيانات غير موثوقة حتى التحقق من مصادرها.
2. **صنّف الهدف:** QUICK_FEEDBACK أو PR_VERIFICATION أو RELEASE_ACCEPTANCE. أثناء التطوير يمكن استخدام اختبارات متأثرة لتسريع الإشارات، لكن لا تستبدل بوابات PR/الإصدار المطلوبة باختبارات مختارة فقط.
3. **اختر أقل استراتيجية كلفة تحافظ على الصحة:** إعادة استخدام نتائج مثبتة سارية، تحليل أثر التغييرات، تقسيم حسب مدد تاريخية، تحسين fixtures، زيادة تزامن محدود مع العزل. إذا كانت الاعتماديات مجهولة وسّع الاختبارات.
4. **خطّة مجمدة قبل التشغيل:** احفظ جرد الاختبارات المختارة، membership لكل shard، تعليمات التشغيل، رأس المصدر وشجرته والفرع الأساس وmerge-base إن كانت ذات صلة، lockfiles، نسخ الأدوات والبيئة، ومفتاح صلاحية. لا تصف نتائج ذات بصمة مختلفة بأنها صالحة.
5. **اضبط الموارد:** افحص CPU quotas/RAM/disk/inodes/DB، ابدأ بعملية واحدة في الحالات المشتركة الثقيلة، ولا تشغّل عمليات preflight متزامنة. القفل المحلي لا يحمي جلسات سحابية أخرى؛ استخدم حجزاً موزعاً عند الحاجة ولا تحرر قفلاً قديماً بالوقت أو PID فقط.
6. **استئناف آمن:** احفظ نتيجة كل دفعة فور نهايتها (exit code، PASS/FAIL/SKIP، JUnit SHA، زمن التنفيذ). بعد الانقطاع تحقق من العمليات الحية والمدخلات والفرع الأساس ومصدر النتائج؛ أعد فقط المقطوع أو الفاشل أو القديم، ولا تكرر فعلاً خارجياً قبل فحص أثره في النظام الهدف.
7. **اعرض الحقائق لا الاستنتاجات:** الزمن المقيس مقارنة بخط أساس مكافئ، التغطية الفعلية لجرد الاختبارات، التخطي، الفشل، عدم الاستقرار، الموارد والبوابات التي لم تُشغّل. التشغيل المجزأ لا يسمى preflight كامل متصل.
8. **حفظ وتسليم:** اكتب نقاط استئناف صغيرة خارج شجرة المصدر عند وجود حارس نظافة الشجرة؛ اعتبر بيئة الحاوية مؤقتة. لا تُنشئ تخزيناً بعيداً أو ترفع سجلات/أسراراً بلا تصريح. قدم خطوة الاستئناف التالية بدقة.

طبّق هذه القواعد ديناميكياً وبقدر الحاجة. إن كانت المهمة بسيطة، اكتف بالاختبارات المباشرة ولا تنشئ بنية إجرائية غير ضرورية.
