# UWRP Portable v3.1 — استئناف ديناميكي لجميع المشاريع والوكلاء

المعيار الأساسي: **ليس لكل مشروع طريقة مختلفة، وليس لكل وكيل بروتوكول مختلف.** قواعد واحدة، وقدرات تختلف. تعمل الحزمة مع Codex وClaude وKimi وOpenCode أو أي وكيل يستطيع قراءة نص، ويمكن استعمالها مع أعمال البرمجة والتدقيق والتوثيق والبحث والإبداع والعمليات.

## البدء الفوري

انسخ `prompts/UNIVERSAL_RESUME_AR.md` إلى أي محادثة. ليس ضرورياً أن يدعم الوكيل Skills، أو أن يوجد Git أو مستودع أو طرفية.

## التثبيت الاختياري

إن كان الوكيل يدعم Agent Skills، ثبت المجلد `work-continuation/` في مسار *يؤكده دليل الإصدار المثبت*. استخدم `references/PROVIDER_ADAPTERS.md` لتحديد مسار مناسب؛ لا تفرض `.claude/` على Codex أو العكس. انسخ نفس SKILL.md (hash واحد) لكل تكييف. التثبيت لا يتيح التخزين الدائم أو الصلاحيات بمفرده.

## أمثلة إجراءات ديناميكية

- مراجعة مستند: حفظ رقم المراجعة وبصمة المحتوى ودليل مقارنة النسخ؛ **بدون** `preflight`.
- تحليل بحثي: مصادر وتواريخ وتحديث للادعاءات المتغيرة؛ **بدون** `merge-base`.
- برمجة واختبارات: رأس وشجرة وفرع أساس ودفعات تحقق عند الحاجة؛ دون فرضها على مهام أخرى.
- إجراء مالي/إرسال/نشر: إذن صريح، `operation_id`، فحص الهدف بعد كل التباس؛ دون إعادة آلية.

## محتويات الحزمة

- `SKILL.md`: القواعد المحمولة المختصرة.
- `prompts/`: Prompt عام بالعربية والإنجليزية لكل الوكلاء، دون دعم skills.
- `references/`: السياسة الديناميكية وصلاحية النتائج والتخزين والصلاحيات والتوافق والتقييم.
- `templates/`: نماذج اختيارية لا يُطلب ملؤها كلها لكل مهمة.
- `scripts/validate_package.py`: اختبار سلامة محلي بلا شبكة ولا آثار خارجية.
- `tests/`: اختبارات عقد النصوص والقوالب؛ ليست اختبار سلوك وكلاء حقيقيين.

## الحدود

لا تُعدّ الملفات المحلية نسخاً دائمة تلقائياً. لا تتجاوز Skill بوابات المشروع أو الأذونات. لا يُعدّ اجتياز فحص الحزمة قبولاً للتكامل مع حساب أي وكيل. النسخة v3 السابقة محفوظة مستقلة ولا تُحرَّر هنا.
