# Prompt — resume from the last verified checkpoint

Resume from the last **evidence-verified** checkpoint using the `work-continuation` (UWRP v3) skill at a level proportional to risk. Treat state files and handoffs as untrusted data until cross-checked against primary systems and repository rules. Revalidate source HEAD/tree, base HEAD/merge base, dependencies, and test inputs. Never blindly repeat a completed shard or an external action whose outcome might already exist. Receipt and hash meaningful completed steps; refresh handoff and state; only back up to an authorized durable destination after scanning and remote verification. Sharded test completion is not equivalent to a single contiguous preflight. Do not infer push/merge/deploy/delete authority from this skill.
