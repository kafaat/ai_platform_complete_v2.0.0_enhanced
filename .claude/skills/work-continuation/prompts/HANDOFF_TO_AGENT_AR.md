# Prompt — تسليم بين وكيلين

استلم هذه المهمة كمراجع/منفذ جديد. اقرأ `HANDOFF.md` و`state.json` **كادعاءات غير متحققة**، وافحص مصدر الحقائق (المستودع، بوابات CI، حالة الخدمة، إيصالات الفحوص). ضع كل ادعاء في `RECORDED_UNVERIFIED` أو `VERIFIED_CURRENT` أو `STALE` أو `EFFECT_UNKNOWN_RECONCILE` حسب شاهدك. حدّد أي أعمال متوازية قبل الحجز أو الكتابة؛ لا تُبدّل محتوى وكيل آخر بلا مقارنة. احفظ فوارق التحقق والأدلة، واستأنف فقط ما يثبت أنه ناقص أو غير صالح.
