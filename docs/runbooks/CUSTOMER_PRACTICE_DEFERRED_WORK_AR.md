## تشغيل الأداتين محلياً

من جذر المستودع، باستعمال بيئة اختبار المشروع. لا يحتاج الأمران قاعدة بيانات أو خدمة مزود:

```bash
PYTHONPATH=services/sahool-platform:. python -m scripts.ops.fieldview_import_preview \
  --input examples/customer_practice_review/fieldview_synthetic.geojson \
  --bindings examples/customer_practice_review/field_bindings_synthetic.json \
  --tenant t1 --output /tmp/fieldview-preview.json

python -m shared.feature_store.practice_review \
  --input examples/customer_practice_review/practice_dataset_synthetic.json \
  --output /tmp/practice-review.json
```

المخرجان خاصان بالمراجعة الداخلية: قد يحتويان معرفات وموقع الحقل، فلا ينشران كعينة مجهولة الهوية تلقائياً. الملفات النموذجية وحدها مصطنعة ويجوز استعمالها لاختبار الأداة.

### عقد محوّل FieldView

المواصفة المحدودة: [Export Formats، محدثة 16 يناير 2020](https://dev.fieldview.com/export-format/)، اطلع عليها في 2026-09-13. تصف ملخص زراعة GeoJSON وليس تصديراً شاملاً لقراءات الأجهزة.

- يقبل `FeatureCollection` و`MultiPolygon` ثنائي الأبعاد، وتاريخ يوم `YYYY-MM-DD` ومساحة موجبة محدودة بوحدة `hectare`. يرفض نظام إحداثيات صريحاً غير EPSG:4326. فحص البنية لا يثبت سلامة المضلع طوبولوجياً أو ملكية الأرض.
- يلزم ربط الحقل الخارجي بـ`tenant_id/field_id/season_id`. الملف نفسه لا يثبت صحة الربط؛ يجلبه المشغل من سجل مسموح له. نسخة موقعة من طلب HTTP ليست ضمن هذه الأداة.
- يحتفظ بالمعرف الخارجي منفصلاً عن الداخلي. لا يحول تاريخ اليوم إلى ساعة مخترعة، ولا المساحة إلى مياه أو مدخلات أو تكلفة.
- يزيل التكرار المتطابق داخل الدفعة ويرفض تعارض محتوى معرف التصدير نفسه. لا يعد ذلك إصلاحاً لتكرار الحفظ بين طلبات سجل العمليات؛ يلزم اختبار قاعدة بيانات لذلك قبل استيراد حي.
- يحتفظ فقط بالإسقاط المدعوم؛ يستبعد `resourceOwner` والبريد والخصائص غير المدعومة. اختبار الذهاب/الإياب يخص هذا الإسقاط، وليس النسخ المطابق لكل بايت في ملف المزود.

### عقد إعداد عينات الممارسات

مدخل الأداة JSON يحوي `records` و`consents` و`policy`؛ المثال الكامل في `examples/customer_practice_review/practice_dataset_synthetic.json`.

| الحقول | المصدر المطلوب ومعناها |
|---|---|
| `tenant_id/customer_id/field_id/season_id/operation_id/source_record_id` | تصدير مخول من السجلات القائمة. العميل المقصود وحدة المزارع/صاحب الإدارة، وليس مستخدم الإدخال الميداني. |
| `event_time/feature_available_at/decision_at` | وقت الملاحظة، ووقت توفر **كل** الخصائص المختارة فعلاً، ووقت القرار. عند تعدد المصادر يستخدم وقت التوفر الأخير؛ قيمة وصلت لاحقاً لا تدخل قراراً سابقاً. |
| `features/feature_units` | قيم أصلية أو مشتقات ذات وحدة معرفة في السياسة. لا تحويل ضمني؛ قيمة `null` لا تصبح صفراً. |
| `labels/label_unit/outcome_at/outcome_recorded_at/matures_at` | نتيجة مقاسة ووحدتها ووقت رصدها وتسجيلها وانتهاء نافذة المتابعة التي يحددها المختص. لا يثبت إدخال تاريخ صحة خطة النضج أو مصدر القياس. |
| `region/crop/language/reported_result` | سياق المقارنة وحالة المتابعة: تحسن/ثبات/ضرر/غير محسوم/عدم استجابة، مع بقاء «غير معروف» ظاهراً. |
| `consents[customer_id]` | سجل غرض `shared_learning`، حالته وتاريخ منحه وانتهاءه ومرجعه والمستأجر. يعاد التصدير من مالك الموافقات قبل كل استخدام؛ الأداة لا تتحقق من توقيع أو هوية المصدر. |
| `policy` | المستأجر وتاريخ المراجعة والحد الزمني والعملاء المحتجزون والخصائص ووحداتها والنتيجة ووحدتها؛ تختار قبل تقييم النموذج. |

ترفض الأداة دفعة من مستأجر آخر أو نسختين متعارضتين للعملية. تستبعد الحالات ذات البيانات غير الكافية مع السبب، وتبقيها في تقرير اكتمال داخلي. تقبل الموافقة السارية لغرضها فقط. نتيجة غير مرصودة بعد نضجها لا تؤهل العينة.

للتدريب، يجب أن تكون الملاحظة متاحة قبل القرار وأن تكون النتيجة مسجلة وناضجة عند الحد الزمني. للتقييم، يكون القرار بعد الحد من عميل محتجز مسبقاً. تحجز كل حقول العميل، وكذلك الحقل الذي انتقل بين عميلين. مئات رسائل العملية نفسها لا تزيد الحالات المستقلة. يفحص المراجع أيضاً قرابة المزارع/الأصول والصور المتكررة التي لا تكشفها المعرفات وحدها.

تعيد الأداة `prepared_for_review` فقط عند وجود مرشحين في القسمين، ولا تحسب هذه الحالة اعتماد تدريب أو فاعلية. تصدر بصمات المصدر والموافقة والسياسة وبيان الخصائص القائم. **لا تغير مسارات Phase 10 الأخرى**؛ لا يجوز اعتبار إضافة هذه الأداة إغلاقاً عاماً لمشاكل التعلم U01–U08 أو حواجز المحادثة.

## بروتوكول التجربة والاستئناف الميداني

هذه ورقة تشغيل للتحضير، وليست إذن تشغيل أو إيصال نجاح. تستعمل مسار القرار والموافقة والأمر والإقرار الحالي بعد قبول السلطة وGATE-01. لا تنفذ الأدوات المحلية أمراً على مضخة.

1. يسجل مسؤول المزرعة والمختص الحقل والموسم والمحصول، والهدف، والمشاركين وموافقتهم، والمعالجة المقارنة، والمقياس والوحدة وخطة النضج وقاعدة الإيقاف. النطاق المقترح الأول قطعة واحدة مع متابعة بشرية؛ يقرر المختص صلاحية أي تغيير زراعي.
2. يثبت معرف جهاز ووحدة تحكم وصمام ومصدر ماء وحدود خطة معتمدة ووقت انتهاءها. يسجل التدفق المقاس/العداد ومعايرته. غياب التدفق يمنع حساب حجم ماء من زمن المضخة.
3. في تجربة مراقبة آمنة، يسجل الأمر والإقرار وبداية العداد. يقطع الاتصال أو الطاقة وفق إجراء المزرعة، ويسجل وقت التوقف ومقدار الماء المقاس قبل الانقطاع. لا يستنتج التنفيذ من HTTP 200 أو إقرار نقل.
4. بعد الرجوع، يقارن حالة الجهاز الفعلية بآخر إقرار دائم ويعيد التحقق من صلاحية القرار والمستأجر والجهاز والخطة والإنذارات. تضارب السجلات أو عداد أُعيد ضبطه يعني مراجعة بشرية، لا تعويضاً حسابياً مخمناً.
5. يبنى المتبقي فقط من هدف صالح وكمية فعلية متسقة. يختبر فقد الرد بعد تنفيذ الأمر وإعادة إرسال **المعرف نفسه**؛ يجب عدم تكرار الصرف. يقارن قراءات العداد قبل/بعد ويثبت الإقرار في السجل ثم يقرأه عبر المنصة.
6. يملأ إيصالاً: نسخة الكود والصورة والإعداد غير السري، وهوية النشر والجهاز، ومعرفات القرار والأمر والإقرار، وقراءات ووحدات ومعايرة وأوقات، ونتيجة كل خطوة، واسم مسؤول القياس ومدة صلاحية الدليل. تبقى النتيجة «لم تقَس» إذا لم تنفذ خطوة.

اختبار الانقطاع المرفق يثبت رفض بيانات قديمة أو مكررة في **الدالة المعزولة** فقط. لا يقيس تشغيل مضخة أو حفظ إقرار أو حجم متبقٍ أو نجاح استئناف فعلي.

## قبول التعلم المحلي والتوسع

يبدأ جدول قبول مستقل لكل منطقة × محصول × لغة × موسم، ويسجل عدد المزارعين والحقول المستقلة، ونسبة المتابعة، والنقص، والضرر، ومصدر القياسات، ومدى صلاحية الترخيص والتغطية. لا تجمع الأعمدة في نسبة نجاح عامة لليمن.

- تحتجز حقول/عملاء وموسماً لاحقاً قبل مقارنة النموذج، وتبقى الأسئلة والصور المتكررة مع الحالة الأصلية. لا تستعمل المعلومات اللاحقة لوقت القرار.
- يراجع مختص الحالات الداعمة والمتعارضة والتكاليف والبدائل المتزامنة. تعد المقارنات الأولى وصفية؛ فصل السبب يحتاج تصميماً زراعياً ومقارنة مناسبة.
- يستكمل خط الأساس والمتابعة والحصاد عند ملاءمته قبل ادعاء الغلة أو الوفورات. الأعداد في المثال اختبار برمجي، ليست عينة ميدانية.
- ترفع ممارسة إلى بطاقة معرفة فقط بقرار مراجعة ونطاق ومدة صلاحية وروابط إلى الحالات ومسوغ الحقوق. تستخدم نتائج «لا دليل كافٍ» لتوجيه جمع البيانات التالي.
- للتجربة التشاركية يمكن الاستفادة من [منصة FAO لمدارس المزارعين الحقلية](https://www.fao.org/farmer-field-schools/en) ومنهج الميسر والملاحظة والمقارنة؛ لا يدعى تنفيذ FFS أو tricot من تعبئة نموذج وحدها.
