# تقييم قيمة سيناريو الري

هذه الشريحة تقارن تنفيذين يدويين موثّقين للحقل والموسم والنظام والمساحة نفسها عبر
`POST /api/v1/outcome/measure` وواجهة العمليات اليدوية. القراءة لا تصدر أمراً للري
ولا تعدّل التوصيات أو النماذج. فرق حجم المياه المرصود لا يثبت وفرًا سببيًا.

## السؤال والقرار

السؤال: هل يقلل جدول الري المقترح استهلاك المياه والطاقة والتكلفة دون تدهور احتياج
المحصول؟ القرار التجريبي: أي حقل يُروى ومتى وبأي مقدار، ضمن قيود المياه والطاقة
والسلامة. يظل اعتماد الخطة وتشغيلها والتحقق المستقل منها في دورة التنفيذ القائمة.

## حدود المقارنة الحالية

اختَر سجل خط أساس وسجلًا مرشحًا مختلفين، بحالة `reconciled` وجودة قياس فعلية
`measured_meter` أو `measured_flow` مع التحقق المستقل والأهلية للسجل المائي.
الخادم يسترجع السجلين في نطاق المستأجر والحقل؛ لا يثق بكميات يرسلها المتصفح.
يعرض الحجم والعمق وزمن التشغيل والفرق الموقّع: خط الأساس ناقص المرشح.
الفرق السالب زيادة في المرشح. اختلاف المساحة أو الموسم أو النظام يمنع المقارنة.
التطابق في الحقل والموسم لا يضبط اختلاف الطقس أو مرحلة المحصول أو رطوبة التربة.
لا تُستخدم تقديرات التدفق الاسمي بوصفها قياسًا فعليًا. الطاقة والتكلفة غير مقاستين
في هذه الشريحة، والأثر السببي غير مثبت، حتى عند نجاح مقارنة المياه.

## التسجيل المسبق قبل تجربة ميدانية

سجّل تصميمًا مؤرخًا ومراجعًا قبل رؤية النتائج: نسخة الخطة والنموذج، حدود السلامة،
مقياسًا أساسيًا واحدًا، طريقة تخصيص الأذرع، حجم العينة وتحليل القوة، التعامل مع
الانقطاع والبيانات المفقودة، ووحدة التجميع وقاعدة القرار وفترات الثقة.
قارن قواعد الري الحالية بالخطة المقترحة مع ضبط الطقس والتربة ومرحلة المحصول؛
استخدم تخصيصًا عشوائيًا أو تصميمًا مقارنًا موثقًا، لا مجرد تنفيذين متتاليين.
سجّل عدم الالتزام بالخطة كما حدث، ولا تستبعده بعد رؤية النتيجة.

## دفتر القيمة المطلوب

| البند | مصدر الدليل المطلوب | التعامل مع النقص |
|---|---|---|
| المياه | عداد السحب أو تدفق مقاس، ومعايرة وهوية العداد | غير مقاس، لا صفر |
| الطاقة | عداد kWh أو وقود فعلي لكل تنفيذ | غير مقاس، لا استنتاج من زمن التشغيل |
| كلفة المياه والطاقة | تعرفة مؤرخة وعملة ونطاق تطبيق | لا تسعير افتراضي |
| الإنتاج والجودة | حصاد ودرجة جودة ومساحة موثقة | لا ادعاء هامش إنتاج |
| العمالة | وقت فعلي وأثر مالي محقق | الوقت الموفر لا يساوي وفرًا نقديًا تلقائيًا |
| النظام | الحوسبة والبيانات والقياس والمراجعة والتشغيل والصيانة | الكلفة الناقصة تمنع صافي قيمة كامل |

صافي القيمة الإضافية = الوفر المحقق + زيادة هامش مساهمة الإنتاج − الكلفة الإضافية
للنظام والقياس والمراجعة والتشغيل. لا تجمع الإيراد والهامش مرتين، ولا تسعّر الحجم
المطلوب ناقص المنفذ كوفر. افصل نتائج القياس عن نسبتها إلى الذكاء الاصطناعي.

## قبول التوسع

لا يُعتمد التوسع حتى تتحقق حدود السلامة والأثر الاقتصادي على الأدلة المسجلة، وتُقاس
كلفة تجهيز مزرعة ثانية وتخصيصها ودعمها. لا تثبت هذه الشريحة تحسن الغلة ولا تحقق
الكلفة ولا تُغلق فجوة `IRRIGATION-OUTCOME-IMPROVEMENT-AND-COST-NOT-MEASURED-01`.
التجميد التشغيلي في `sahool-brain/hot.md` يبقى ساريًا: لا نشر ولا تشغيل ميداني هنا.
