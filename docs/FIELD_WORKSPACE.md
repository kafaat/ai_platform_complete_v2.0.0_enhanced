# مساحة عمل الحقل (Field Workspace)

تنفيذ الفكرة الأعلى أثراً من دراسة **FieldView / John Deere**: *الخريطة محور +
طبقات قابلة للتبديل + خطّ زمنيّ للعمليّات* — **بنمط سهول الصادق** (لا تلوين مفبرك،
لا تاريخ مخترَع، طبقة عرض لا تفرض قراراً).

## المكوّن: `core/engines/field_workspace.py` (نواة نقيّة)

| الدالّة | الوظيفة |
|--------|---------|
| `layer_availability(field)` | توفّر كلّ طبقة بصدق: **متاحة** (من أعمدة الحقل) / **عند الطلب** (طبقات الأقمار NDVI/NDMI — لا تُخزَّن) / **غير متوفّرة** |
| `normalize_timeline(events)` | بطاقات خطّ زمنيّ من أحداث **مسجّلة فقط** (الأحدث أوّلاً) بتسمية عربيّة + فئة |
| `assemble_workspace(field, terrain, events)` | تجميع: ملخّص + طبقات + تفسير تضاريس (#64) + خطّ زمنيّ |

**كتالوج الطبقات:** NDVI · NDMI (أقمار، عند الطلب) · الارتفاع · المنحدر · الاتّجاه
(تضاريس) · نوع التربة · الملوحة (تربة) · نظام الريّ (ماء).

## النقطة: `GET /api/v1/fields/{field_id}/workspace`

محميّة بـ`FIELD_VIEW` عبر RLS. تجمع: صفّ الحقل + الأحداث (`events`) + تفسير
التضاريس، وتُرجِع نموذج العرض. 404 لو الحقل ليس للمستأجِر، 503 عند تعذّر القاعدة.

```
{ field_id, display_only:true, field:{name_ar,crop,area_ha,soil_type},
  layers:[{key,label_ar,category,available,status,note_ar}],
  available_layer_count, terrain:{...enrich_terrain},
  timeline:[{occurred_at,event_type,op_ar,category,issue_tags}], timeline_total }
```

## نمط سهول مقابل المصدر (الصدق المحفوظ)
- **طبقات الأقمار** (NDVI/NDMI): `on_demand` لا «متاحة» — تُجلب عند الطلب إن توفّرت
  صورة صافية؛ لا تلوين لطبقة بلا بيانات (خلافاً لـmaximalism المنصّتين).
- **الخطّ الزمنيّ**: من `events` المسجّلة فقط — فارغ بصدق لو لا أحداث (لا اختراع).
- **عرض لا قرار**: `display_only:true` — يصف الحقل ويعرضه، لا يفرض.

## الواجهة (الطبقة المستهلِكة — تصميم)
شاشة «مساحة عمل الحقل»: خريطة الحقل مركزها + مبدّل طبقات (يُخفي/يُظهر، ويُعلن
«عند الطلب» لطبقات الأقمار) + خطّ زمنيّ أسفلها (بطاقات بأيقونة الفئة). تستهلك
`GET /fields/{id}/workspace` في نداء واحد. (الموبايل Flutter: offline-first — تُخزَّن محليّاً.)
