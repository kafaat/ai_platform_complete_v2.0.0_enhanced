# معايرة التنبّؤ من التاريخ المتراكم — التعلّم التدريجي الحقيقي

## الفكرة (طلبك)
الحقول المسجّلة (توقّع ← نتيجة فعليّة) تتراكم عبر المواسم لتصبح ذاكرة تاريخيّة
تُحسّن التنبّؤ تدريجيّاً.

## اكتشاف: سهول يملك معظم اللبنات
  • recommendation_log: يسجّل (توقّع,نتيجة) + يحسب MAPE (حجم الخطأ) ✓
  • multi_season_analytics: اتّجاهات عبر المواسم (analyze_yield_trend) ✓
  • trueup: معامل تصحيح k لحقل واحد ✓
  • farm_memory/farm_ledger: تاريخ كامل + compare_seasons ✓

## الفجوة الحقيقيّة المسدودة
سهول يعرف **حجم** الخطأ (MAPE) لكن لا **اتّجاهه المنهجي**: هل نُفرط في
التقدير دائماً أم نُقلّل؟ ولا يطبّق ذلك لتصحيح التنبّؤ القادم. هذه الحلقة
الأخيرة (bias correction) كانت مفقودة.

## ما بُني: core/learning/prediction_calibration.py
  • analyze_systematic_bias: الخطأ **الموقّع** (الاتّجاه) لا المطلق فقط
    - إفراط منهجي (+) → تصحيح يخفّض | تقليل (−) → تصحيح يرفع
  • apply_calibration: يطبّق التصحيح شفّافاً (قبل/بعد/السبب)
  • calibration_maturity: نضج المعايرة لكلّ سياق (محصول×منطقة)

## الذكاء/الصدق
  • **تمييز العشوائي عن المنهجي**: خطأ متوازن (±متناوب) → لا تصحيح اتّجاهي
    (MAPE قد يكون عالياً لكن الانحياز ~0 → لا نصحّح وهماً)
  • **تدريجي مخمّد** (وزن shrinkage = n/(n+K)، K=30؛ سقف الحذر MAX_DAMPING=0.6
    يقصّ المعامل إلى [0.4، 1.6]): لا قفزة تلغي النموذج الأساسي ولا تنبّؤ سالب
  • **عيّنة كافية**: ≥3 أزواج (MIN_PAIRS_FOR_SIGNAL) + ≥2 مزرعة (تجنّب pseudoreplication)
  • **لكلّ سياق**: الانحياز يختلف بالمحصول×المنطقة

## السلوك المُتحقَّق
  • عيّنة صغيرة → لا تصحيح (1.0)
  • إفراط +25% → ×0.875 (يخفّض، مخمّد) | تقليل −20% → ×1.1 (يرفع)
  • خطأ متوازن → unbiased، 1.0 (لا تصحيح زائف)
  • تطبيق: خام 5.0 → معدّل 4.375 (−12.5%) شفّاف

## المبدأ المحفوظ
  • مدفوع بالبيانات: لا تصحيح قبل عيّنة كافية (لا اختراع)
  • تدريجي (مخمّد): تعلّم لا قفزة
  • حتمي شفّاف: إحصاء من أزواج موثّقة، لا صندوق أسود
  • يتّسق مع learning_activation + recommendation_log + farmer_agency

## الخلاصة: الحلقة التراكميّة اكتملت
الآن سهول يملك السلسلة الكاملة للتعلّم التدريجي:
  ١. recommendation_log يسجّل (توقّع,نتيجة) عبر المواسم [ذاكرة]
  ٢. learning_activation يقرّر متى تكفي البيانات [بوّابة]
  ٣. prediction_calibration يحوّل التاريخ لتصحيح منهجي [تعلّم] ← الجديد
  ٤. التصحيح يُطبَّق تدريجيّاً على التنبّؤ القادم [تحسين]
كلّما تراكمت مواسم، تحسّن التصحيح — تعلّم تدريجي حقيقي من بيانات فعليّة،
مخمّد، شفّاف، لكلّ سياق. لا نموذج يتعلّم من فراغ، بل إحصاء صادق من التاريخ.
