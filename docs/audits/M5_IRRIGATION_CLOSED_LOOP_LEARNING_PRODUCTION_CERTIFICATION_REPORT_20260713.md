## Safety and governance

- Complete SHA-256 lineage is required across decision, authorization, execution plan, as-applied truth, water-ledger event and outcome evidence.
- Identity mismatches across tenant, field, season, decision and execution plan fail closed.
- Learning proposals are always `review_required=true` and `auto_adjust=false`.
- A minimum field sample count is required before a proposal becomes review-ready.
- Production certification requires all named runtime gates, a digest for each gate, a complete evidence-pack digest, production environment, certifier identity and certification timestamp.
- No controller, MQTT, Modbus or actuator dispatch was added.

## Honest certification boundary

This package implements the production-certification contract and fail-closed evaluator, but it does not claim that production is certified in this environment. The following evidence must still be generated by a real deployment:

- PostgreSQL migration execution and rollback evidence
- live tenant RLS isolation
- live Weather, Soil, Decision, Controller and Actuator connectivity
- durable idempotency and replay tests
- fail-safe recovery and interruption tests
- end-to-end receipt, verification, ledger and outcome reconciliation
- observability and immutable audit evidence

Until every required runtime gate supplies a valid evidence digest, `production_certified` remains false.
