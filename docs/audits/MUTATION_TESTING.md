# اختبار الطفرات — قياس قوّة الاختبارات (النوع 4 من هرم التحقّق)

«هل يوجد اختبار **قادر على إثبات** خاصّيّة؟» لا «هل يوجد اختبار؟». الأداة
`scripts/mutation_probe.py` تُطفِّر وحدة هدف (قلب منطق زراعيّ نقيّ) وتُشغّل **اختباراتها
الفعليّة** على كلّ طافِر؛ طافِر ينجو (لا يفشل أيّ اختبار) = ثغرة في قوّة الاختبارات.

## التشغيل (عند الطلب — ليس بوّابة CI لبطئه)
```bash
PYTHONPATH=services/sahool-platform python scripts/mutation_probe.py \
  services/sahool-platform/core/<module>.py -- <pytest test files...>
```
الأداة نفسها مُختبَرة بـ`tests_v9/test_mutation_probe.py` (سريع، في CI) كي لا تنحدر.

## المُشغِّلات
مقارنات (`>↔>=`، `<↔<=`، `==↔!=`)، حسابيّة (`+↔-`، `*↔/`)، منطقيّة (`and↔or`)،
ثوابت منطقيّة (`True↔False` بالهويّة — لا تُطفَّر الأعداد تفادياً للضجيج).

## خطّ الأساس: cross_domain_optimization (محرّك أمثَلة الريّ)
بعد تقوية الاختبارات (`_clamp01` بقيم دقيقة + قيم ذهبيّة للمخرج + `candidates_evaluated`):

| | |
|---|---|
| الطفرات | 22 |
| قُتِلت | 13 |
| نجت | 9 |
| **الدرجة** | **59%** |

**كلّ الطفرات ذات الأثر القراريّ قُتِلت** (الكمّيّة المُطبَّقة، الدرجات، عدد المرشّحين،
الماء الموفَّر). الناجون التسعة **ليسوا ثغرات منطق قرار**:

| السطر | الطافِر | التصنيف |
|---|---|---|
| L37 (×2) | حدود `_clamp01` (`x<0`، `x>1`) | **مكافِئ** — clamp(0)=0، clamp(1)=1 في الحالتين (لا يُقتَل بأيّ اختبار) |
| L59 | شبكة `range(steps+1)` | شبه-مكافِئ (دقّة الشبكة؛ الأمثل عند نقطة شبكيّة يُلتقَط) |
| L64 | argmax `score > best` | شبه-مكافِئ (كسر التعادل) |
| L69,L71,L73,L74 | فروع نصّ `tradeoffs_ar` العربيّ | **تجميليّ** (شرح للمستخدم، لا مخرَج قرار) |

## الخلاصة
اختبار الطفرات **أكّد قوّة اختبارات منطق القرار** على المحرّك الحرج، ووجّه تقوية فعليّة
(`_clamp01` لم يكن له اختبار مباشر). الدرجة لا تبلغ 100% بسبب **الطفرات المكافِئة** (لا
فرق سلوكيّ) — وهو حدّ معروف لاختبار الطفرات، لا ضعف في الاختبارات. تُطبَّق الأداة على أيّ
وحدة نقيّة حرجة عند الحاجة (القرار الموحّد، قياس الأثر، الذكاء الاقتصاديّ، band_math).
