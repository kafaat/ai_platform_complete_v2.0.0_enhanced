# فهرس منظومة الذكاء المناخي-الزراعي (SAHOOL)

> التدفّق المتكامل: **من موقع الحقل إلى قرار الزراعة** — موثّق ومترابط.

## التدفّق الكامل (المنظومة كعقل واحد)

```
  المزارع ينقر موقع حقله على الخريطة (GPS)
            │
            ▼
  ① geo_zone_locator.locate_field(lat, lon, elevation)
     → المحافظة + الإقليم المناخي + المناخ السائد
            │
            ▼
  ② agro_climate_zones.suited_for_zone(zone)
     → المحاصيل الملائمة + ما يُتجنّب + التنبيه المائي
            │
            ├──▶ ③ climate_analogs.analogs_for_zone(zone)   [صحراء داخليّة فقط]
            │      → دليل عالمي مطابق (الجوف السعوديّة/النقب) + محاصيل مثبتة
            │
            ├──▶ ④ seasonal_risk.zone_risk_calendar(zone)
            │      → نوافذ المخاطر (موجات حرّ/صقيع/مطر حصاد)
            │      + chill_hours_estimate → ملاءمة الأشجار المتساقطة
            │
            ▼
  ⑤ crop_suitability + crop_introduction.check_field_fit
     → فحص ملاءمة الحقل المحدّد (تربة/ملوحة/pH)
            │
            ▼
  ⑥ farm_economics.feasibility
     → الجدوى الاقتصاديّة (هل يستحقّ؟)
            │
            ▼
  ⑦ propagation_advisor + planting_calendar + water_balance
     → كيف تبدأ (الإكثار + موعد الزراعة + الريّ)
```

## الطبقات الجديدة (هذه الجلسات) ومسؤوليّاتها

| الوحدة | المسؤوليّة | المصدر الموثّق |
|--------|-----------|-----------------|
| `agro_climate_zones` | 6 أقاليم مناخيّة-زراعيّة + تصنيف بالارتفاع | CEFAS + جغرافيا اليمن |
| `geo_zone_locator` | إحداثيّات GPS → محافظة + إقليم | FAO GAEZ/GeoNetwork + وزارة الزراعة |
| `seasonal_risk` | نوافذ المخاطر الموسميّة + ساعات البرودة | علم المناخ الزراعي + بيانات الأقاليم |
| `climate_analogs` | مناطق عالميّة مشابهة + محاصيلها المثبتة | Saudipedia + Arab News + أبحاث |
| `propagation_advisor` | الإكثار الخضري + اختيار الأصل المقاوم | Wikifarmer + مراجع جامعيّة |

## مبادئ الصدق المطبّقة عبر المنظومة

- **لا توصية بلا معرفة الإقليم** — الموقع يسبق كلّ شيء
- **الارتفاع يحسم** المناخ لا الحدود الإداريّة (تعز: المخا ≠ صبر الموادم)
- **المناطق المشابهة للصحراء الداخليّة فقط** — لا الساحل الرطب
- **التفاح/البنّ للمرتفعات فقط** — مُستبعدان من السهول الحارّة (ساعات برودة)
- **تحذير استنزاف المياه** (البرسيم) + **تحذير الملوحة** (الأفوكادو)
- **لا اختراع أصناف يمنيّة** — التوجيه لهيئة البحوث والإرشاد الزراعي
- **لا تخمين** — مكان مجهول/إحداثيّات خارج اليمن → رسالة صادقة لا افتراض
- **إقرار الطموح البعيد** — لا تنبّؤ مناخي 10 سنوات، لا microclimate بلا مستشعرات
