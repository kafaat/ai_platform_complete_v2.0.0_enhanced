### ٤. langchain: تحقّقت من GitHub/PyPI (لاحظتَ أنّه فشل سابقاً)
- **النتيجة**: langchain وصل **1.x** (آخر langchain 1.3.2، langchain-core 1.4.1).
  **لكن**: قيود مشروعك `>=0.3.0,<1.0` **صحيحة ومقصودة** — لأنّ:
  - langchain 1.x **كاسر**: أزال `langchain.retrievers`، وغيّر `RetrievalQA`.
  - كودك يستخدم `RetrievalQA` — الترقية لـ1.x تكسره (تحتاج إعادة كتابة LCEL).
  - **السبب الذي فشل سابقاً كان المرآة الصينيّة لا الإصدار** (أُصلح).
- **ما أصلحتُه فعلاً**: `from langchain_community.vectorstores import Qdrant`
  (مهمَل) → `from langchain_qdrant import QdrantVectorStore` (الحزمة المخصّصة).
  أضفتُ `langchain-qdrant>=0.2.0,<1.0`. حدّثتُ الاستيراد + type hints + الاستدعاء.
  متوافق: QdrantVectorStore يتطلّب خادم Qdrant >=1.10 — لدينا 1.17.1 ✓.
