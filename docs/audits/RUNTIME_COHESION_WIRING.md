# معالجة Runtime Cohesion: ربط الأنظمة الفرعيّة بحلقة القرار

ردّاً على المراجعة الثانية المنصفة (الأنظمة موجودة لكنّ بعضها مترابط جزئيّاً)،
رُبط farm_memory + simulation بحلقة القرار الموحّدة فعليّاً في الكود.

## المشكلة (كما شخّصتها المراجعة الثانية بدقّة)
run_field_intelligence كان graph قرار يربط:
```
collect → normalize → compose_field_state (fusion) → assess_economics
  → _derive_policy (decision) → guardrails
```
لكنّ farm_memory و simulation كانا **أنظمة فرعيّة قويّة منفصلة** — تُستدعى من
نقاط أخرى (supervisor-agent، endpoints مستقلّة)، لا من حلقة القرار. "ترابط
جزئي" كما وصفت المراجعة.

## الحلّ المطبّق (في الكود، لا توثيق)
أُضيف للحلقة طوران جديدان (⑥ و⑦) بعد الحَوكمة:

**⑥ farm_memory** (memory_fn): يجلب السياق التاريخي للحقل، يكشف القضايا
المتكرّرة (ملوحة/إجهاد يتكرّر ≥مرّتين)، ويُغني القرار:
`decision["historical_context_ar"]` ← "ملوحة تتكرّر في هذا الحقل".

**⑦ simulation** (simulate_fn): يشغّل what-if للإجراء المقترَح (مع/بلا تدخّل)،
يقارن المحصول، ويُعلن في القرار إن كان الإجراء لا يُجدي:
`decision["simulation_caveat_ar"]`. يُشغَّل فقط إن القرار actionable.

## مبادئ التصميم (محفوظة)
1. **الدمج يبقى مرّة واحدة**: الربط في المنسّق (graph القرار)، لا في
   compose_field_state (مبدأ "الدمج لا يتوسّع" محفوظ).
2. **اختياري + توافق خلفي**: memory_fn/simulate_fn اختياريّان؛ بدونهما السلوك
   القديم سليم تماماً (مُختبَر).
3. **fail-safe**: فشل أيّ نظام فرعي لا يُسقط القرار — الخطأ مُعلَن لا مُخفى
   (السياق إثراء لا شرط).
4. **محوّلات حيّة**: memory_adapter (يقرأ events history، يكشف التكرار) +
   simulate_adapter (يطلب what-if من WOFOST). صدق: None عند التعذّر، لا تاريخ
   ولا أرقام مخترَعة.

## المخرج الموحّد (الآن)
field-intelligence/analyze يُرجِع graph قرار كامل:
operational_truths + policy_decision + governance + **farm_memory_context**
+ **simulation** + alerts — كلّها من حلقة واحدة.

## ملاحظة صدق
عالجتُ Runtime Cohesion **في الكود فعليّاً** (لا توثيق): الأنظمة الفرعيّة الآن
في graph القرار الموحّد، مُختبَرة حيّاً. الحدّ المعلَن: المحوّلات الحيّة
(memory_adapter/simulate_adapter) تطلب نقطتين على المنصّة (`/fields/{id}/history`
و`/simulate/what-if`) — إن لم تكونا مبنيّتين على جهازك بعد، المحوّل يُرجِع None
بصدق (لا يكسر القرار، يُعلن التعذّر). الـgraph جاهز ومُختبَر؛ تغذيته الحيّة
الكاملة تحتاج هاتين النقطتين على بيئة التشغيل. لم أزعم أنّهما مبنيّتان.
