# إصلاح خطأ _md2 (ترتيب التهريب)

## الخطأ (اكتشفته المراجعة بالتشغيل لا القراءة)
دالّة _md2 كانت تضع الشرطة المائلة \\ **آخر** المجموعة (ومكرّرة \\\\)، فتُعيد
تهريب كلّ الشرطات التي أضافتها التهريبات السابقة:
  '12.5'  → '12\\\\\\\\.5'  (٨ شرطات — تيليجرام يرفضها 400)
عمليّاً أسوأ من قبل الإصلاح — يضمن فشل كلّ رسالة فيها رقم عشري.

## الإصلاح
الشرطة المائلة **أوّلاً ومرّة واحدة**:
  for ch in "\\\\_*[]()~`>#+-=|{}.!":
النتيجة (متحقّق منها بالتشغيل):
  '12.5'    → '12\\.5'      ✓ (شرطة واحدة)
  '(القمح)' → '\\(القمح\\)'  ✓
  'اسم_حقل' → 'اسم\\_حقل'    ✓
  'صحة 95%' → 'صحة 95%'      ✓ (لا رمز محجوز)

## اختبار ارتداد
أُضيف test_telegram_md2_escape:
  assert _md2("12.5") == r"12\\.5"
يمنع عودة هذا الخطأ تحديداً.
