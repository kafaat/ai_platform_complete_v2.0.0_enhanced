# الأتمتة والربط التلقائي + رأي في n8n/workflows

## هل n8n وأدوات workflows مفيدة؟ (إجابة متوازنة)

### مفيدة لـ (أتمتة محيطيّة خارجيّة):
- إشعارات Telegram/بريد عند تنبيه
- مزامنة Odoo
- جدولة سحب بيانات من أنظمة خارجيّة عبر webhooks
- تدفّقات بسيطة يعدّلها غير المبرمجين بصريّاً

### مضرّة لـ (لا تستخدمها هنا):
- **منطق القرار الزراعي** (الريّ/التناقض/WOFOST) — قلب النظام، يجب أن
  يبقى في كود مُختبَر (288 اختبار)، لا صناديق n8n غير قابلة للاختبار الآلي
- التنسيق الحرج بين الخدمات — لديك NATS JetStream + supervisor + event_bus
- أيّ شيء يحتاج lineage/ثقة/تتبّع — مبنيّ أصلاً في الكود

### الحكم
n8n طبقة **محيطيّة اختياريّة** لو رغبت لاحقاً بربط أنظمة خارجيّة بصريّاً.
ليس بديلاً عن منطقك، ولا ضروريّاً الآن — NATS + الجدولة الجديدة تكفيان
للتنسيق الداخلي. إضافته الآن = تبعيّة + سطح تشغيلي جديد بلا عائد فوري.

## ما بُني للأتمتة (بدل n8n — داخلي قابل للاختبار)

### api/scheduler.py — جدولة مهامّ دوريّة خفيفة
- asyncio خالص، بلا تبعيّة خارجيّة
- تسجيل مهامّ بفاصل زمني + دالّة async
- **عزل**: فشل مهمّة لا يُسقط البقيّة (try/except + backoff تصاعدي بسقف ساعة)
- **مراقبة**: آخر تشغيل/نجاح/فشل + عدّاد لكلّ مهمّة
- تفعيل/تعطيل وقت التشغيل
- يبدأ/يتوقّف مع دورة حياة التطبيق (startup/shutdown)

### المهامّ القياسيّة المُعرّفة
- fetch_weather (يوميّاً) — يُربط بـOpen-Meteo حين تتوفّر المفاتيح
- scan_new_imagery (كلّ 6س) — فحص صور Sentinel الجديدة
- check_decision_freshness (كلّ ساعة) — مُفعّل الآن (لا يحتاج تبعيّات)

صدق: لا نسجّل مهمّة فارغة تدّعي عملاً — تُسجَّل فقط حين يتوفّر منطقها.

### endpoint المراقبة
GET /api/v1/automation/scheduler-status — حالة كلّ مهمّة (للكشف عن توقّف
أتمتة أو فشل متكرّر).

## ما رُبط تلقائيّاً
- الجدولة تبدأ تلقائيّاً عند إقلاع sahool-platform (lifespan)
- فحص النضارة الدوري يعمل دون تدخّل
- تتكامل مع event_bus الموجود (نمط outbox) للنشر الموثوق

## التحقّق
- backend: 288/288 (+5) · 144 endpoint · e2e 9/9 · Qualification 6/6
- اختبار الجدولة: عزل + مراقبة + تفعيل/تعطيل + توقّف نظيف

## ملاحظة صدق (الحدود)
- لا أشغّل asyncio loop الحقيقي للتطبيق هنا — اختبرتُ الجدولة بمعزل
  (asyncio.run) وأثبتُّ العزل والمراقبة. التشغيل الكامل مع المهامّ الفعليّة
  (سحب طقس حقيقي) يتمّ على خادمك.
- سحب الطقس/الصور مُعرّف هيكليّاً لكن غير مربوط بالمصادر الفعليّة (يحتاج
  مفاتيح API + pool) — صدق: لم أدّعِ أتمتة سحب لا تعمل.
