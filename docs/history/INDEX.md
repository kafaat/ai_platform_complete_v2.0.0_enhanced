# أرشيف السجلّات اللحظيّة (docs/history)

هذا المجلّد يحوي السجلّات التاريخيّة لجولات المراجعة والإصلاح والبحث في
SAHOOL. هذه **لقطات لحظيّة** تعكس حالة المشروع وقت كتابتها — لا تُحدَّث بأثر
رجعي (قِدَمها جزء من قيمتها كسجلّ تطوّر).

للحالة الحاليّة الحيّة، انظر الوثائق المرجعيّة في جذر المشروع:
- README.md — نظرة عامّة تشغيليّة
- SYSTEM_INDEX.md — فهرس المنظومة والتدفّق
- SOURCE_OF_TRUTH.md — مصدر الحقيقة للبيانات
- OPERATIONAL_CONTRACTS.md — عقود التشغيل
- INVARIANT_MANIFEST.md — الثوابت (invariants)
- TEMPORAL_AUTHORITY.md — سلطة الزمن (occurred_at)

## فئات الأرشيف
- **REVIEW*/DISPOSITION*/CRITIQUE*** — سجلّات جولات المراجعة الخارجيّة وردودها
- **\*_FIXES/\*_FIX_\*** — سجلّات الإصلاحات
- **\*_RESEARCH/\*_ANALYSIS** — أبحاث الوكيل المجالي (تربة/مؤشّرات/مناطق)
- **\*_IMPLEMENTATION/\*_HARDENING** — سجلّات تنفيذ الميزات
- **SAHOOL_v8\*/v9\*** — لقطات توثيق إصدارات سابقة

> ملاحظة: ٣ ملفّات بحثيّة (ZONE_SAMPLING_RESEARCH, SOIL_INDICES_RESEARCH,
> ONBOARDING_QUESTIONNAIRE) مُشار إليها كمراجع توثيقيّة في docstrings الكود
> المقابل — المسارات مُحدَّثة لـdocs/history/.
