# الطبقة الرابعة: زيوت عطريّة + أعلاف موفّرة للماء + ربط الطبقات بالقرار

## ١. ربط طبقات الفرص بمحرّك القرار
القرار للصحراء يرفق الآن تلقائيّاً:
- `high_value_opportunities_ar`: الجوجوبا/المورينجا/الألوفيرا
- `niche_export_opportunities_ar`: الصمغ العربي/الحبّة السوداء/الجوار + الميزة اليمنيّة
صنعاء (مرتفعات) → لا فرص صحراويّة (ربط دقيق محفوظ).

## ٢. النباتات العطريّة (aromatic_crops) — قيمة عالية لكلّ قطرة ماء
| النبات | المنتج | الماء |
|--------|--------|-------|
| إبرة الراعي العطريّة | زيت راقٍ (شبيه الورد) | منخفض-متوسّط |
| اللافندر | زيت + سياحة زراعيّة | منخفض (لا يحتاج برودة) |
| الزعتر | زيت + توابل (تراث يمني) | منخفض |
| إكليل الجبل | زيت + طهي | منخفض جدّاً |
| المريميّة | شاي + زيت | منخفض |

**صدق**: القيمة في التقطير (الزيت) لا العشب الخام؛ حسّاسة للجفاف الشديد.

## ٣. الأعلاف الموفّرة للماء (fodder_alternatives) — حلّ معضلة البرسيم
| العلف | الميزة |
|-------|--------|
| **Blue panic** | الأفضل علميّاً (بروتين عالٍ + ملوحة) — دراسة الإمارات |
| Mombasa grass | إنتاج عالٍ متحمّل للحرارة |
| السورغم/الدخن العلفي | تراث + توفير ماء |

**يربط بدرس أريزونا**: البرسيم يستنزف الجوفي — هذه بدائل تقلّل الاستهلاك.
**صدق**: تقلّل الماء لا تلغيه؛ قيمتها في توفير الاستيراد لا التصدير.

## Endpoints (2)
- GET /aromatic-crops/list
- GET /fodder-alternatives/list

## الصورة الكاملة: 4 طبقات فرص موثّقة
1. **أساسيّة**: نخيل/زيتون/رمّان/عنب (strategic_tiers)
2. **عالية القيمة**: جوجوبا/مورينجا/ألوفيرا/كينوا (high_value_crops)
3. **متخصّصة تصديريّة**: صمغ عربي/جوار/حبّة سوداء/قرطم (niche_export_crops)
4. **عطريّة + أعلاف**: لافندر/زعتر/جيرانيوم + Blue panic (aromatic_fodder)

كلّها مربوطة بمحرّك القرار للصحراء، موثّقة بأدلّة عالميّة، موسومة بصدق.
