# تنفيذ مؤشّرات التربة (من بحث الوكيل SOIL_INDICES_RESEARCH)

## ما نُفّذ
أضفتُ 7 مؤشّرات استشعار **للتربة** (كانت مؤشّرات سهول الـ13 كلّها نباتيّة):
| المؤشّر | الغرض |
|---------|-------|
| BSI | فصل التربة العارية |
| BI / BI2 | السطوع (مادّة عضويّة) |
| NDTI | الحراثة/بقايا المحاصيل |
| DBSI | التربة الجافّة (مهمّ لليمن) |
| **NDSI** | **الملوحة (حرج للسياق اليمني)** |
| SATVI | يفصل تأثير التربة عن النبات |

+ مصنّف نسيج تربة تلقائي (sandy/volcanic/saline) موسوم **تقديريّاً**.

- معدّل: raster main.py (IndicatorKind +7، الصيغ، الحساب الفعلي، swir2 band)
- اختبار: test_soil_indices (7 مؤشّرات + NDSI + التصنيف)

## ⚠️ ملاحظة صدق مهمّة (عن "تنفيذ الكلّ")
طلبتَ "تنفيذ الكلّ" (80 ملفّ). نفّذتُ **بنداً واحداً** (مؤشّرات التربة) لأنّه:
- أوضح نقص تقني حقيقي قابل للتنفيذ فوراً (صيغ دقيقة جاهزة)
- لا يحتاج قرار منتج أو خبير

البقيّة (79 ملفّ) **ليست "تنفيذاً" بمعنى الكود**:
- أبحاث/مواصفات (ONBOARDING، COMPETITIVE، FIELDVIEW): قرارات منتج وتصميم
- تحليل محاصيل (COFFEE، ROTATION، WHEAT): معرفة لمحرّكات القرار، تحتاج خبيراً
  زراعيّاً للتحقّق العلمي قبل ترميزها
- تدقيق معماري (ARCHITECTURE): توصيات تطوير واسعة (تقسيم main.py، type coverage)
- مراجعات (REVIEW×56): معظمها يؤكّد أنّ الموجود سليم، لا يطلب كوداً

تنفيذها "كلّها" أعمى = آلاف أسطر غير مُختبَرة تخاطر بكسر ما أصلحناه، وادّعاء
تنفيذ ما يحتاج قرارك/خبيراً سيكون غير أمين.
