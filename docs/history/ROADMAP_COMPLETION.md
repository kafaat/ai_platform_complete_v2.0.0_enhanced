# حالة خارطة الطريق — اكتمال الميزات

تحديث: جلسة "أكمل الجميع مع البدء بالأكثر فائدة".

## ✅ المرحلة ١ (الميزات) — مكتملة
- البند ٧: Field Timeline (`field_timeline.py`)
- البند ٨: Scouting Pins (`scouting_pins.py` + `pinRepo.ts`)
- البند ٩: Manual Application (`manual_converter.py` + `walk_plan.py` + PDF + `WalkPlanScreen.tsx`)
- **البند ١٠: Quick Onboarding** (`data/yemenCrops.ts` + `QuickOnboardScreen.tsx`) —
  قوائم يمنيّة محمّلة مسبقاً (٨ محاصيل + أصناف + تربة + أسمدة + ريّ + محافظات)،
  اختيار بأزرار بأقلّ كتابة، offline، RTL.

## ✅ المرحلة ٢ — مكتملة
- **البند ١١: محرّك التجارب t-test/LSD** (`trial_engine.py`) — اختبار t مزدوج +
  LSD عبر scipy، حُكم صادق ("مؤكّد إحصائيّاً" / "لا فرق")، يرفض <4 كتل. طُوبق ضدّ
  scipy مباشرة. + `trial_randomization.py` (توزيع حتمي قابل للتحقّق).
- **البند ١٢: ميزان الماء ET0** (`water_balance.py`) — FAO-56 Penman-Monteith +
  Hargreaves-Samani احتياطي (مهمّ للمحطّات اليمنيّة القليلة)، Kc حسب المرحلة،
  مطر فعّال USDA-SCS. قيم ET0 فيزيائيّة معقولة (~5-6 مم/يوم هضبة).
- **البند ١٣: قواعد 4R الكلسيّة** (`nutrient_4r.py`) — N (تطاير الأمونيا، تجزئة،
  banding)، P (محجوب بلا Olsen-P)، Fe/Zn (ورقي، محجوب بلا تحليل). يحجب ٣/٤ بلا
  مختبر (الاستشعار يوجّه/المختبر يحكم).

## ✅ المرحلة ٣ — مكتملة
- **البند ١٤: مناطق NDVI k-means** (`zones_kmeans.py`) — تجميع sklearn، ترتيب
  low/medium/high، منخفضة الثقة → problem، تحذير تشبّع NDVI. للفحص لا للقرار الآلي.
- **البند ١٥: تتبّع GDD** (`gdd_tracker.py`) — حرارة متراكمة، عتبات مراحل لـ٥
  محاصيل، سقف حرارة، تنبّؤ المرحلة التالية.
- **البند ١٦: تشخيص بقواعد الأعراض** (`disease_diagnosis.py`) — شجرة قواعد شفّافة
  (لا ML)، ٨ قواعد + ٢٤ عرَض، ثقة معزّزة بالدعم، توصية تأكيد بشري/مختبر.
  يجسّد "rule-based before ML".

## المبادئ المطبّقة
- الصدق الإحصائي: t-test يقول "لا فرق" بصدق (البند ١١)
- المختبر يحكم: 4R يحجب بلا تحليل (البند ١٣)
- rule-based قبل ML: تشخيص بقواعد لا صورة (البند ١٦)
- human-in-the-loop: المناطق/الريّ توصية لا قرار آلي (١٢/١٤)
- لا ثوابت مُختلقة: لا EONR بثوابت أمريكيّة؛ Kc/GDD موسومة "تحتاج معايرة"
- React Native لا Flutter: البند ١٠ بُني بـRN/TS
