# شريط صور الأقمار الزمني + الرسم البياني للمؤشّرات (أسفل الخريطة)

## الطلب
عرض صور الأقمار كشريط timeline أسفل الخريطة لمقارنة حالة الحقل عبر فترات
سابقة + رسم بياني للمؤشّرات خلال الموسم.

## ما بُني (مكوّنان جديدان + تكامل MapScreen)

### ١. ImageStripTimeline.tsx — شريط الصور الزمني
- شريط أفقي قابل للتمرير من صور Sentinel-2 عبر الموسم (الأحدث أوّلاً، RTL)
- كلّ مصغّرة: تاريخ + نسبة غيوم + لون المؤشّر (أو thumbnail حقيقي)
- النقر على صورة → مقارنة (onSelect) يعرض بياناتها
- علامة "درون" للصور من الطائرات المسيّرة
- حالات: تحميل / لا صور / صور متاحة

### ٢. SeasonIndicatorChart.tsx — الرسم البياني
- منحنى NDVI عبر الموسم باستخدام react-native-svg (متاح في المشروع)
- محور سيني: تواريخ · محور صادي: قيمة المؤشّر (مدى ديناميكي)
- نقاط ملوّنة بقيمة المؤشّر (ndviToColor) + شبكة + تسميات
- يضبط المدى تلقائيّاً على القيم الفعليّة للوضوح

### ٣. تكامل MapScreen
- شريط الصور + الرسم في لوحة أسفل الخريطة (maxHeight 240، قابلة للتمرير)
- عند اختيار حقل: يجلب صور الموسم تلقائيّاً (searchSeasonImagery، ٦ أشهر)
- زرّ "احسب NDVI لرسم اتّجاه الموسم" يعالج أحدث ٨ صور عبر raster-service
- النقر على صورة في الشريط يعرض بياناتها (مقارنة)

## مبدأ الصدق (مهمّ جدّاً)
- **لا قيم NDVI وهميّة**: البحث يُرجع الصور وبياناتها (تاريخ/غيوم) فوراً،
  لكنّ قيمة NDVI لكلّ صورة تتطلّب معالجة فعليّة عبر raster-service
- **الرسم البياني يظهر فقط** عند توفّر قيمتين فعليّتين على الأقلّ
- قبل المعالجة: يظهر زرّ "احسب" (شفّاف) بدل رسم فارغ أو مزيّف
- المعالجة تتخطّى الصور الفاشلة بدل اختراع قيم

## التحقّق
- ✓ فحص TypeScript للمشروع كامل: صفر أخطاء منطقيّة
  (أصلحتُ خطأين موروثين في stub الحقل: farm_id + last_observation_at)
- ✓ react-native-svg مستخدم بشكل صحيح (Polyline/Circle/Line/Text)
- ✓ تطابق البيانات: stacItemToMarker ← searchSeasonImagery ← raster-service

## الأثر
المزارع يرى الآن أسفل الخريطة:
١) **شريط صور حقله عبر الموسم** — يضغط أيّ صورة ليقارن حالته في تواريخ مختلفة
٢) **رسم بياني لاتّجاه NDVI** — يرى صعود/هبوط صحّة محصوله عبر الزمن
بصدق تامّ: القيم من معالجة فعليّة لصور الأقمار، لا تقديرات وهميّة.
