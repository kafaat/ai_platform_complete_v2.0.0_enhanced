# فحص تطابق الواجهات مع الخلفيّة والخدمات

## النطاق
واجهتان (موبايل React Native + ويب React) ضدّ خلفيّة من خدمات متعدّدة.
الفحص شمل: المسارات، الخدمات المستدعاة، عقود البيانات، أنواع TypeScript.

## ١. الموبايل ↔ الخلفيّة — ✅ متطابق تماماً
- 53 مساراً يستدعيها الموبايل، كلّها لها مقابل في الخلفيّة (167 مساراً)
- اختبار العقد الرسمي: 2/2 (مسارات + auth prefix)
- أنواع TypeScript: صفر أخطاء (فحص المشروع كامل)
- عقود البيانات الحسّاسة متطابقة:
  - /field/operational-state → validity, execution_mode ✓
  - /consistency/irrigation → consistent, conflicts ✓
  - /irrigation/moisture-decision → irrigation_amount_mm ✓
الموبايل (98 ملفّ) هو الواجهة الأساسيّة الناضجة — تطابق سليم.

## ٢. الويب ↔ الخلفيّة — ⚠ تباعد معماري حقيقي
الويب (frontend/src/services/api.ts) يفترض **معماريّة microservices كاملة**،
يستدعي كلّ خدمة على منفذها:
| استدعاء الويب | الخدمة المتوقّعة | الواقع |
|---------------|------------------|--------|
| /v1/indicators/* | indicators-service:8091 | ✗ **stub فارغ** (لا منطق) |
| /weather/* | weather-service:8092 | stub رفيع (صحّة فقط) |
| /soil/* | soil-service:8094 | فيه منطق لكن **معلّق في compose** |
| /vegetation/* | vegetation:8090 | فيه منطق ✓ |

**السبب**: المنطق الفعلي (143 endpoint) موحّد في sahool-platform، بينما
الويب يتوقّع خدمات منفصلة. هذا تباعد بين توقّع الواجهة وبنية الخلفيّة.

### لماذا لم أُصلحه تلقائيّاً (صدق)
إصلاحه يتطلّب قراراً معماريّاً ليس لي اتّخاذه نيابةً عنك:
- **خيار أ**: توجيه الويب لـsahool-platform مباشرةً (تغيير base URLs +
  مسارات في api.ts) — أبسط، يطابق الواقع الحالي.
- **خيار ب**: ملء الخدمات الـstub بالمنطق الفعلي (فصل حقيقي
  لـmicroservices) — أنظف معماريّاً لكن عمل كبير وتكرار منطق.
- **خيار ج**: Kong gateway يوجّه /v1/indicators إلى sahool-platform
  (طبقة توجيه) — وسط.

القرار يعتمد على رؤيتك: هل الويب واجهة مستقبليّة لمعماريّة موزّعة، أم
يُوجَّه للموحّد الآن؟ الموبايل (الأساسي) يعمل بصحّة مع sahool-platform.

## ٣. الخدمات المستقلّة (raster/auth/vegetation)
- raster-service: 13 مسار (Sentinel-2 + Sentinel-1) — يستدعيه الموبايل
  عبر raster.ts/imagery.ts ✓

- vegetation: 6 مسارات ✓

## الخلاصة
- **الموبايل**: تطابق كامل وسليم (الواجهة الأساسيّة) ✓
- **الويب**: يستدعي خدمات بعضها stub فارغ — تباعد يحتاج قرارك المعماري ⚠
- لا كسر في عقود البيانات أو الأنواع حيثما الخدمة موجودة
