# قائمة الفحص البصري لشاشات SAHOOL (ما قبل التسليم)

مستلهَمة من فكرة "Anti-Slop pre-flight checklist" (مشروع taste-skill)، لكن
**مكيّفة لواقع SAHOOL**: لوحة تحكّم زراعيّة عربيّة RTL — لا صفحة هبوط.

## لماذا التكييف ضروري؟
taste-skill مصمّم صراحةً لصفحات الهبوط والمعارض، **لا للوحات التحكّم**
(يستثنيها نصّاً). SAHOOL لوحات/خرائط/جداول/تدفّقات إدخال — فـ"السلوب" عندنا
مختلف تماماً. قائمتنا تركّز على ما يهمّ منصّتنا فعلاً.

## أداة الفحص الآليّة
`scripts/visual_qa_check.mjs` — تفحص كلّ الشاشات آليّاً:
```
node scripts/visual_qa_check.mjs        # تقرير إرشادي
QA_STRICT=1 node scripts/visual_qa_check.mjs   # بوّابة (تفشل عند 🔴)
```

## الفحوص السبعة (مكيّفة لـSAHOOL)
| الفحص | الخطورة | لماذا يهمّ المزارع اليمني |
|-------|---------|--------------------------|
| قيم وهميّة غير موسومة | 🔴 عالية | يخالف مبدأ الصدق — لا أرقام مخترعة |
| لا معالجة أخطاء | 🔴 عالية | الشبكة تنقطع كثيراً — يجب ألّا تنهار |
| لا حالة فارغة | 🟡 متوسّطة | حقل جديد/بلا بيانات يجب أن يُرشد لا يُربك |
| لا مؤشّر تحميل | 🟡 متوسّطة | شبكة بطيئة → شاشة جامدة تبدو معطّلة |
| ألوان hex مباشرة | 🟡 متوسّطة | تشتّت بصري — يُفضّل نظام الألوان |
| RTL مفقود | ⚪ منخفضة | نصّ عربي قد يظهر يساريّاً |
| أزرار بلا وصوليّة | ⚪ منخفضة | كبار السنّ/ضعاف البصر |

## القائمة اليدويّة (ما لا تكشفه الأداة)
الأداة تكشف الأنماط؛ هذه تحتاج عيناً بشريّة:

### الصدق (الأهمّ في SAHOOL)
- [ ] هل كلّ رقم معروض من بيانات فعليّة (لا تقدير معروض كحقيقة)؟
- [ ] هل الرسوم البيانيّة تعرض قيماً محسوبة فقط (لا نقاط وهميّة)؟
- [ ] هل التوصيات الزراعيّة من القواعد/المراجع (لا هلوسة)؟
- [ ] هل التقديرات موسومة "سيناريو لا وعد"؟

### الوضوح للمزارع
- [ ] هل المصطلحات الزراعيّة مفهومة لمزارع لا خبير بيانات؟
- [ ] هل الوحدات واضحة (مم/هكتار/درجة)؟
- [ ] هل الألوان دلاليّة متّسقة (أحمر=خطر، أخضر=صحّي)؟

### الواقع اليمني
- [ ] هل تعمل الشاشة دون اتّصال (offline-first)؟
- [ ] هل الصور مضغوطة قبل الرفع (شبكة بطيئة)؟
- [ ] هل هناك طابع "آخر تحديث" للبيانات المخزّنة؟

## ما كشفته الأداة وعُولج
- **FieldsListScreen** (🔴): استدعاء API دون try/catch → أُضيفت معالجة أخطاء
  + رسالة عربيّة + عدم إسقاط القائمة عند فشل جلب موسم حقل واحد.

## الملاحظات المتبقّية (مقصودة أو منخفضة)
- LiveDashboardScreen "قيم وهميّة": محاكاة setTimeout موسومة (stub معروف،
  يُستبدل ببيانات حيّة عند ربط /api/v1/dashboard)
- "ألوان hex": كثير منها دلاليّ مقصود (ألوان NDVI، حالات) — راجع السياق
- "لا حالة فارغة": بعض الشاشات نماذج إدخال لا تعرض قوائم (لا تحتاج)

## مبدأ الصدق في الأداة نفسها
- الأداة **إرشاديّة لا قاطعة** (تحذيرات للمراجعة البشريّة)
- لا تدّعي أنّها تكشف كلّ شيء — العين البشريّة لا بديل عنها
- بعض ما تكشفه مقصود — السياق يحكم

## الأثر
SAHOOL الآن لديه **بوّابة جودة بصريّة** قابلة للتكرار، مكيّفة لمنصّة زراعيّة
عربيّة لا صفحة هبوط. تُشغّل قبل كلّ تسليم، تكشف الأنماط المشكلة، وتترك
القرار النهائي للمراجع البشري — تماماً كروح "ما قبل التسليم" في المرجع،
لكن لحالتنا الحقيقيّة.
