# مخطّط البستان المختلط الاستثماري (لوز/زيتون/فستق)

## المراجعة الصادقة للوثائق
الوثائق قدّمت نموذجاً استثماريّاً قويّاً (بستان مختلط). تحقّقتُ من أرقامها
مقابل مصادر موثوقة (Wikifarmer + American Pistachios + Olive Oil Source +
دراسات Frontiers):

| الرقم | الوثيقة | المصدر الموثّق | الحكم |
|-------|---------|-----------------|-------|
| كثافة الفستق | 100-200/هكتار | ~272 (6×6م) | ✓ محافظ |
| إنتاج الفستق | 10-25 كجم/شجرة | 6-10 كجم (نضج) | ⚠ متفائل قليلاً |
| بداية الفستق | 5-7 سنوات | 7-10 (تجاري) | ✓ |
| ذكر:إناث | 1:8-10 | 1:8-12 | ✓ |
| الزيتون يبدأ | 3-5 سنوات | 3-5 | ✓ |
| اللوز يبدأ | 3-4 سنوات | 3-4 | ✓ |

**تحذير جوهري من البحث**: في المناطق الجافّة الكثافة العالية تسبّب تنافساً
شديداً على الماء وتخفض الإنتاج — لذا اعتمدتُ كثافات محافظة.

## ما بُني
### بطاقتا الفستق واللوز (crop_introduction → 27 بطاقة)
- **الفستق**: أعلى قيمة، عائد بطيء (7-10 سنوات)، حسّاس للملوحة/التشبّع،
  ذكر لكلّ 8-10 إناث. تحذير: لا يُزرع منفرداً (مخاطرة عالية).
- **اللوز**: توازن سرعة/ربح، عائد سريع (3-4 سنوات)، محرّك التدفّق النقدي.

### orchard_planner.py
- `mixed_orchard_plan(area_ha)`: توزيع (لوز 50%/زيتون 30%/فستق 20%) +
  كثافة + مسافات + جدول تدفّق نقدي زمني + تحذير الكثافة الصحراويّة
- `orchard_economics_note(area_ha)`: تأسيس 4-8 آلاف$/هكتار + مراحل العائد
  (تتناسب خطّيّاً مع المساحة)

### الربط بمحرّك القرار
القرار للصحراء يرفق `mixed_orchard_ar` تلقائيّاً (نموذج + استراتيجيّة + تحذير).

## Endpoints (2)
- GET /orchard/plan?area_ha=
- GET /orchard/economics?area_ha=

## مبدأ الصدق المطبّق
- **الأرقام الاقتصاديّة موسومة "سيناريو لا وعد"** — تتذبذب بشدّة مع السوق
- **تحذير الكثافة الصحراويّة** (تنافس مائي) مبنيّ على بحث محكّم
- **عائد الفستق صُحّح** من 10-25 إلى 6-10 كجم (الموثّق)
- **لا فستق منفرداً** — يُدمج مع اللوز والزيتون لتقليل المخاطرة
- التنويه: يحتاج دراسة جدوى ميدانيّة + خبير + تحليل بئر فعلي

## القيمة
يحوّل رؤية "البستان المختلط" إلى مخطّط قابل للحساب (أشجار/مسافات/جدول زمني)
مربوط بمحرّك القرار — مع صدق صارم في الأرقام الاقتصاديّة والكثافات.
