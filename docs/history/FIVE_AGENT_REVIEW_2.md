- **B1 عاد في النسخة المرفوعة** (سطر apt مشوّه \\ curl \\) — أُصلح.
- **B5 كان ناقصاً**: link_account معرّفة لكن بلا أمر /link يستدعيها —
  المستخدم لم يكن يستطيع الربط فعليّاً. أُضيف:
  - أمر /link كامل (LinkStates: email → password → auth/login)

- مؤكّد سليم: HEALTHCHECK pgrep، USER non-root، يُترجم، صفر jwt.encode.
