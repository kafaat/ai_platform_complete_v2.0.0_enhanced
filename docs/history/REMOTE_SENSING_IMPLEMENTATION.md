# تنفيذ توصيات تقرير المقارنة — الاستشعار عن بُعد

نُفّذت كلّ التوصيات من تقرير المقارنة العالمي، بالترتيب حسب الأولويّة، مع
تحقّق وظيفي وعدم كسر.

## ✅ P0 — أولويّة عالية (مُنفَّذة)

### ١. خادم بلاطات ديناميكي (TiTiler)
- أُضيفت خدمة sahool-titiler لـdocker-compose (ghcr.io/developmentseed/titiler)
- TITILER_URL env في raster-service
- endpoint /layers/{id}/tilejson: يُرجِع رابط TiTiler ديناميكي من COG (تمدّد
  ألوان + colormap عند الطلب) عند توفّره، وإلّا البلاطات الثابتة fallback
- صدق: يُبلّغ بالمصدر الفعلي (titiler-dynamic vs static-pregenerated)

### ٢. التحليل الزمني (Time-Series)
- وحدة time_series.py: تركيب الوسيط الشهري (median compositing لتخفيف الغيوم)
  + اتّجاه خطّي (تحسّن/تدهور) + كشف شذوذ (z-score للإجهاد/الآفات)
- endpoints: /imagery/timeseries (يبحث STAC + بنية زمنيّة) +
  /imagery/timeseries/analyze (يحلّل قيماً محسوبة)
- صدق: لا يخترع قيم NDVI من البحث وحده — يجمّع قيماً حقيقيّة مُمرَّرة

## ✅ P1 — أولويّة متوسّطة (مُنفَّذة)

### ٣. مؤشّر NDRE (النيتروجين/red-edge)
- enum + formula + band math: (NIR-RedEdge)/(NIR+RedEdge)
- نطاق rededge أُضيف لـBandMapping؛ الأتمتة تمرّره (B5)
- + MSI (Moisture Stress Index = SWIR1/NIR) للإجهاد المائي

### ٤. مناطق الإدارة + الوصفات متغيّرة المعدّل (VRT)
- وحدة management_zones.py: تقسيم أداء بالكوانتايل (عالٍ/متوسّط/منخفض) +
  مناطق ثبات عبر الزمن (CV) + وصفة VRT (تعويض/حماية)
- endpoint /zones/classify
- صدق: معامِلات الوصفة إرشاديّة، المعدّل النهائي قرار agronomic
