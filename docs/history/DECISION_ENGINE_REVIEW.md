# محرّك القرار الزراعي الموحّد (عقل الحقل) + مورد السيول الواردة

## ١. مورد السيول الواردة (water_harvesting)
الحزم منطقة تجمّع سيول من أحواض أعلى (صعدة/عمران/صنعاء) عبر وديان
(مذاب/العولة/الخارد) — "ميزاب اليمن الشرقي". الماء الزراعي المتاح > المطر
المحلّي النقطي (~80-95مم). `upstream_flood_water()`:
- يوضّح المفهوم + مثال الحزم الموثّق
- يربط بحصاد المياه (العقوم/الحواجز) + الملوحة (السيول تغسل الأملاح) + المخاطر
- تحذير: موسميّة (1-4 أحداث/سنة) + قد تكون مدمّرة + مكمّلة للجوفي لا بديلة

Endpoint: GET /water-harvesting/upstream-flood

## ٢. محرّك القرار الزراعي (decision_engine) — تتويج المنظومة
**منسّق (orchestrator)** يربط كلّ الوحدات في قرار واحد. لا معرفة جديدة —
يستدعي الموجود ويجمعه. المزارع يُدخل موقعاً (+تربة/مساحة) → قرار متكامل.

### التدفّق المنسّق (6 خطوات)
1. تحديد الإقليم (GPS عبر geo_locator / اسم عبر agro_climate_zones)
2. محاصيل الإقليم الملائمة + استراتيجيّة الماء
3. الدليل العالمي + التصنيف الاستراتيجي (للصحراء فقط)
4. المخاطر الموسميّة + ساعات البرودة
5. فحص التربة (تنبيهات ملوحة EC≥4 / قلويّة pH≥7.8)
6. اعتبار المساحة (صغير→قيمة عالية، كبير→مكننة)

### مثبت بالاختبار (حقل الحزم 16.16, 44.78, 1100م)
- GPS → الجوف → صحراء داخليّة ✓
- يجمع: دليل عالمي (الجوف السعوديّة) + تنبيه ملوحة (EC5) + تنبيه قلويّة (pH8)
- ملخّص ذكي: يتجنّب التفاح (لا برودة) + يرتّب المحاصيل الصحراويّة الفاخرة
- صنعاء (مرتفعات) → لا دليل صحراوي (ربط دقيق)
- تعز (متعدّدة الأقاليم) → يطلب تحديد المديريّة (صادق، لا يخمّن)

Endpoint: GET /decision/for-location?lat=&lon=&elevation_m=&soil_ph=&soil_ec_dsm=&area_ha=

### إصلاح جانبي
صحّحتُ صناديق إحداثيّات مأرب/الجوف ليُسنَد الحزم للجوف بدقّة (كان يُطابق مأرب
لتداخل الصناديق).

## المبدأ
المحرّك يرتّب الخيارات بشفافيّة (لماذا) لا يفرضها. القرار النهائي للمزارع.
كلّ مكوّن يحمل تنويهه. لا تكرار منطق — تنسيق خالص للوحدات الموجودة.

## القيمة
يتوّج المنظومة: المزارع لم يعد يستعلم عن 12 وحدة منفصلة، بل يُدخل موقعه
فيحصل على قرار واحد متماسك يجمع المناخ + الملاءمة + المخاطر + الدليل +
الاقتصاد + الخطوات. هذا "عقل الحقل" الذي تطمح إليه الوثائق.
