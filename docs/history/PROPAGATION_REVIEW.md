# جانب جديد: الإكثار الخضري (اللاجنسي) + اختيار الأصل المقاوم

## المصدر
مقال Wikifarmer عن الإكثار اللاجنسي/الخضري للنباتات + مراجع جامعيّة.

## الفجوة
بطاقات الإدخال تضمّ أشجاراً تُكثّر **خضريّاً** لا بالبذور (مانجو، حمضيات،
تين، رمّان، أفوكادو، عنب، جوافة، نخيل)، لكن لا إرشاد لكيفيّة إكثارها — ولا
للنقطة المحوريّة لليمن: **اختيار الأصل (rootstock) المقاوم**.

## ما بُني: `propagation_advisor.py`
- `propagation_methods()`: 5 طرق (عقل/تطعيم/برعمة/تقسيم/ترقيد) + مزاياها
- `method_guide(method)`: دليل كلّ طريقة (الأنواع + النصيحة)
- `crop_propagation(crop)`: الطريقة المناسبة لكلّ شجرة إدخال
- `rootstock_selection(stress)`: اختيار الأصل حسب الإجهاد

## طريقة الإكثار لكلّ شجرة
| الشجرة | الطريقة | السبب |
|--------|---------|-------|
| المانجو | تطعيم | أصل مقاوم، يثمر أسرع |
| الحمضيات | برعمة | أصل مقاوم للملوحة (نهج نجران) |
| الأفوكادو | تطعيم | حسّاس للملوحة → أصل مقاوم |
| التين/الرمّان/العنب | عقل خشبيّة | تتجذّر بسهولة |
| الجوافة | ترقيد | هوائي أو عقل |
| النخيل | تقسيم (الفسائل) | تحافظ على الصنف |

## ⭐ الربط المحوري: اختيار الأصل المقاوم (rootstock)
المقال يكشف جوهر نجاح نجران: **الأصل يُختار للمقاومة** (جفاف/ملوحة/أمراض/
تقزيم)، **والطعم يُختار لجودة الثمار**. `rootstock_selection` يربط:
- الملوحة → وحدة إدارة الملوحة
- الجفاف → وحدتا حصاد المياه وحساسيّة الريّ
- الأمراض → وحدة IPM

## Endpoints
- GET /propagation/methods
- GET /propagation/method-guide?method=grafting
- GET /propagation/crop?crop=citrus
- GET /propagation/rootstock?stress=salinity

## مبدأ الصدق
- الإكثار الخضري **ينقل أمراض الأمّ** → استخدم أمّاً سليمة
- الاعتماد على أصناف قليلة متطابقة = **هشاشة وراثيّة** (الموز/البنّ/الكيوي
  خسرت تاريخيّاً)
- التطعيم مهارة تحتاج تدريباً

## القيمة + الربط
يكمّل بطاقات الإدخال: لا تقل "ازرع المانجو" فقط، بل "أكثرها تطعيماً على أصل
مقاوم للملوحة". يربط الإدخال (ماذا) + الملاءمة (هل يناسب) + الإكثار (كيف
تبدأ) + اختيار الأصل (كيف تقاوم إجهاد أرضك) — منظومة شجريّة متكاملة على نهج
نجران الموثّق.
