الجولة الافتراضية الشاملة سجلت إخفاق جناح الوحدة المذكور ثم عولج؛ لا يوصف سجلها التاريخي بأنه صفر إخفاقات. اشتقاق Capability-Impact وفحص رسالة الالتزام يُستكملان على الالتزام قبل الدفع، وفق بروتوكول المستودع.
