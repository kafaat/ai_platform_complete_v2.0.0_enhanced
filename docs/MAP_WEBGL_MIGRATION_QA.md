# Map Engine — MapLibre GL (WebGL) Migration · QA & Closure Gate

حالة طبقة الخرائط في SAHOOL ومسار الانتقال التدريجيّ من Leaflet (2D) إلى MapLibre GL
(WebGL) خلف عَلَم، على نهج Climate FieldView / John Deere Operations Center — دون نزع
مكدّس Leaflet العامل ودون أيّ انحدار للمسار الافتراضيّ.

## العَلَم والموقف الافتراضيّ

- `frontend/src/lib/featureFlags.ts` → `MAP_ENGINE`:
  - **الافتراضيّ دائماً: `leaflet`** (محرّك مستقرّ، مُختبَر، كامل الميزات).
  - **`maplibre` تجريبيّ خلف العَلَم فقط**: `VITE_MAP_ENGINE=maplibre`.
- محرّك MapLibre (`components/maphub/HubMapGL.tsx`) و Terra Draw **مقسومان بالكود** (lazy)؛
  لا يدخلان الحزمة الأساسيّة حين العَلَم مُطفأ (مُثبَت: `maplibregl`/`TerraDraw` = 0 في
  `dist/assets/index-*.js`).

## بوّابة الإغلاق الإنتاجيّ للمرحلة 2ب (اختبار متصفّح حيّ واحد)

شغّل المحرّك التجريبيّ محلّيّاً:

```bash
cd frontend
VITE_MAP_ENGINE=maplibre npm run dev
# أو: echo 'VITE_MAP_ENGINE=maplibre' > .env.local && npm run dev
# أو للبناء الحقيقيّ: VITE_MAP_ENGINE=maplibre npm run build && npm run preview
```

ثمّ في «الحقول والخريطة» (Map Hub) تحقّق من:

- [ ] **1. رسم مضلّع** عبر أداة Terra Draw (وضع «مضلّع»). — **مُؤتمَت (Playwright)** ✅
- [ ] **2. قياس** مساحة (مضلّع) وطول (خطّ) — تظهر القيم في لوحة القياس. — **مُؤتمَت
      (Playwright)** ✅ (يرسم مضلّعاً/خطّاً بنقرات canvas ويؤكّد `measure-area`/`measure-length`).
- [ ] **3. إضافة pin** في وضع الدبابيس (المؤشّر crosshair، يظهر 📍). — **مُختلَط**: تفعيل
      الوضع + إرشاد الدبّوس **مُؤتمَت** ✅؛ أمّا إضافة الدبّوس بنقرة على الـcanvas فهي
      **يدويّة-بصريّة** (حدث MapLibre `click` لا يُطلَق من نقرة اصطناعيّة تحت SwiftShader
      headless — `@visual` غير حاجز؛ لا نُزيّف نجاحاً).
- [ ] **4. تفعيل التراكبات**: طقس / تنبيهات / أجهزة — تظهر العلامات على نقاط الحقول، وما
      لا حقل/هندسة له يُعَدّ في ملاحظة (لا إحداثيّ مُختلَق). — **مُؤتمَت (Playwright)** ✅
      (التبديلات الثلاث بلا أخطاء console وبقاء الخريطة؛ عدّ علامات DOM مغطّى في اختبار
      الوحدة `HubMapGL.test.tsx`).
- [ ] **5. zoom / pan** سلس بلا أعطال. — **مُؤتمَت (Playwright)** ✅ (wheel + drag بلا أخطاء
      console وبقاء الخريطة).
- [ ] **6. اختيار الحقول** يعمل بالنقر، **ولا يتعارض** مع وضع الدبابيس (في وضع الدبابيس
      يُضاف pin ولا يُختار حقل). — **مُختلَط**: اختيار الحقل من القائمة وإبرازه **مُؤتمَت**
      ✅؛ القمع البصريّ لنقر الخريطة في وضع الدبابيس **يدويّ-بصريّ** (يعتمد على نقر
      canvas — انظر القيد في الخطوة 3).
- [ ] **7. لا إزاحة** بين موضع المؤشّر والرسم/العلامة. — **يدويّة-بصريّة** (`@visual`،
      `test.fixme`): قياس إزاحة دون-بكسليّة على لوحة WebGL لا يُقاس بثبات تحت SwiftShader.
- [ ] **8. الالتقاط الحيّ** (المرحلة 3): قرب حدّ حقل قائم يلتصق الرأس به؛ زرّ «التقاط
      للحدود» يبدّل السلوك. — **مُختلَط**: تبديل `aria-pressed` لزرّ الالتقاط **مُؤتمَت**
      ✅؛ التصاق الرأس الفعليّ بالحدّ **يدويّ-بصريّ**.
- [ ] **9. مقارنة بصريّة** لنفس الحقل بين `leaflet` و`maplibre` — تطابق الحدود/المؤشّر.
      — **يدويّة-بصريّة** (`@visual`، `test.fixme`): تطابق بكسل على GPU حقيقيّ (لا
      `toHaveScreenshot` تحت SwiftShader headless — لا تُسقِط البوّابة).

### تشغيل السويت المُؤتمَتة

```bash
cd frontend && npm run e2e          # أو: npm run e2e:ui للوضع التفاعليّ
```

تبني السويت الواجهة بـ`VITE_MAP_ENGINE=maplibre` وتُشغّلها عبر `vite preview` (بلا
خلفيّة؛ التركيبات تُعترَض في طبقة Playwright)، ثمّ تُشغّل Chromium حقيقيّاً بـWebGL
برمجيّ (SwiftShader). في CI: وظيفة **`frontend-e2e`** (`.github/workflows/ci.yml`).

**الجزء المُؤتمَت الحاجز** يغطّي: تحميل WebGL + أسلاك طبقات الحقول، رسم المضلّع/الخطّ
وقيم القياس، لوحة الرسم/أوضاعها، تفعيل التراكبات وzoom/pan بلا أخطاء، اختيار الحقل
وإبرازه، وتبديل التقاط الحدود. **الجزء البصريّ** (٧ و٩ + النقرات على الـcanvas في ٣/٦)
يبقى **توقيعاً بصريّاً يدويّاً** على عتاد GPU حقيقيّ — `@visual`/`test.fixme`، غير حاجز.

**نجاح كلّ ما سبق ⇒ Phase 2b WebGL parity = CLOSED ✅** (عندها يجوز التفكير في ترقية
الافتراضيّ، لا قبله).

## ملاحظات صدق دائمة

- محرّر حدود الحقل (`AddFieldWithMap`, Leaflet) يبقى على التقاطه **ما بعد الإتمام**
  (`snapRing`)؛ الالتقاط الحيّ أُضيف لأداة رسم **GL** فقط.
- رياضيّات الالتقاط مُعاد استخدامها بالكامل من `lib/geo` (مصدر واحد، مُختبَر) — لا تكرار.
- الدبابيس محلّيّة (جلسة) في كلا المحرّكين — لا نقطة قراءة استكشاف خلفيّة بعد.
- لا بيانات/طبقات مُختلَقة: الحقول/الأساس/المؤشّر/التراكبات من مصادر حقيقيّة فقط.
