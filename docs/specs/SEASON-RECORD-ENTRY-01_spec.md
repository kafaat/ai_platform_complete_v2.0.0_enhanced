# SEASON-RECORD-ENTRY-01 — واجهة إدخال سجلّ الموسم (مواصفة v2 — معتمدة بأربعة تعديلات)

**الحالة:** معتمدة من المالك بأربعة تعديلات ملزمة (v2) — تُؤرشَف وتُبنى.
**النطاق:** الجسر الذي يحوّل أساس SEASON-RECORD-01 (v201، مُقفَل `0c109fa` — CI أخضر مؤكَّد) إلى **أداة ترقيم فعليّة**.
**المبدأ الحاكم:** الوصول ≠ الثقة · القبول فعل حسّاس بهويّة مُصدَّقة من الحافّة · لا نسخة ثانية من منطق الهندسة · لا مسار منصّة جديد.

---

## 1. المعمارية (قرارات محسومة)

- **المالك:** `scout-ingest-service` (كاتب واحد للجداول الخمسة).
- **الواجهة:** صفحة داخل خدمة المالك — **لا مسار على sahool-platform**.
- **الهندسة:** الحقل يُنشأ أوّلاً عبر مسار تسجيل الحقول القائم؛ الموسم يشير بـ`field_id` (TEXT، اقتران فضفاض).
- **دورة الحياة:** `untrusted` (مسودّة قابلة للتعديل) → مراجعة بشريّة → `accepted` (تُجمَّد مدخلات المعايرة، triggers v201).

## 2. النقاط (كلّها على scout-ingest-service — صفر مسار منصّة)

| النقطة | الغرض | الحماية |
|---|---|---|
| `POST /internal/seasons` | إنشاء مسودّة (untrusted) لحقل موجود | service-token + tenant |
| `PATCH /internal/seasons/{id}` | تحديث تدريجيّ — مسموح **ما دام untrusted**؛ على accepted ⇒ **409** | service-token + tenant |
| `POST /internal/seasons/{id}/logbook` | رفع مرفق الدفتر (شرط قبول) | service-token + فحص محتوى |
| `GET  /internal/seasons/{id}/logbook` | رابط presigned قصير العمر للمرفق | service-token + tenant |
| `POST /internal/seasons/{id}/accept` | **القبول (حسّاس)** — يحرّر calibration_eligible | **هويّة مُصدَّقة من الحافّة + دور مُراجِع** |
| `GET  /internal/seasons?status=untrusted` | استئناف المسودّات | service-token + tenant |

## 3. تحقّقات القبول (بوّابة accept)

`logbook_image_ref` موجود وصالح · `accepted_by` مُصدَّق من الحافّة (لا مجهول) · القيود 1-3 (لا مستقبل/مدى/حصاد-بعد-زراعة) ·
حدث بلا كمّيّة ⇒ `low_confidence` أو quarantine · طاقة بلا دليل ⇒ quarantine.

## 4. الأمن والتخزين (التعديلات الملزمة ①③)

### ① تصديق الحافّة (الفجوة الجوهريّة) — HMAC، لا اعتماد على التهوية الشبكيّة
داخل شبكة docker، أيّ خدمة/مهاجم في حاوية يستطيع POST مباشرة إلى منفذ scout-ingest بترويسة `X-User-Id` ملفّقة —
والتجريد عند nginx **لا يحميه**. لذا (خيار المالك **أ**، الأقوى):
- nginx يوقّع الهويّة المُشتقّة: `X-Edge-Attestation = HMAC-SHA256(secret, X-User-Id + "\n" + X-Roles + "\n" + timestamp)`
  بمفتاح `SEASON_EDGE_HMAC_KEY` **مشترك بين nginx والخدمة فقط** (secret manager، لا في compose — فئة B).
- الخدمة (على مسارات القبول/الهويّة) **تتحقّق من HMAC + نافذة زمنيّة (≤120ث ضدّ إعادة اللعب)**؛ الهويّة **بلا تصديق صالح ⇒ 401**.
- **برهان سلبيّ:** طلب مباشر من حاوية أخرى (بلا `X-Edge-Attestation` أو بتوقيع خاطئ) + `X-User-Id` ملفّقة ⇒ **401** — لا يُقبل.
- nginx يجرّد أيّ `X-User-Id`/`X-Roles`/`X-Edge-Attestation` واردة من العميل ويعيد بناءها من JWT المُتحقَّق (لا تمرير عميل).

### ③ فحص المرفق بالمحتوى لا بالامتداد + وصول presigned
- **magic bytes** (لا ترويسة MIME التي يزوّرها العميل): `FF D8 FF`=JPEG · `89 50 4E 47`=PNG · `25 50 44 46`=PDF — غيرها ⇒ رفض.
- **الحجم ≤10MB يُقاس بعد الاستلام** (لا Content-Length المزعوم).
- التخزين: مخزن الكائنات القائم (`object_store`, MinIO/S3) تحت `season-logbooks/<tenant>/<season_id>/<sha>.<ext>`.
- **الوصول عبر URLs presigned قصيرة العمر** (≤300ث) — لا مفتاح كائن يُتداول مباشرة. `logbook_image_ref` = مفتاح داخليّ لا يُسرَّب.
- fail-closed: S3 غير مُهيّأ ⇒ `file://` مُعلَّم (تطوير)؛ لكن **القبول يتطلّب مرفقاً صالحاً** (الدفتر «التوقيع» الوحيد).

## 5. أسئلة المراجعة — ✅ محسومة كلّها (v2)

1. **مصادقة القبول** ✅ — هويّة مُصدَّقة من الحافّة بـHMAC (§4-①)، لا ترويسة عارية (درس ADR-0033). نمط SEC-3.1/FE-P0 slice 4.
2. **دور المُراجِع** ✅ — الاسم الحرفيّ **`season-reviewer`**، يُسجَّل في مطالبة `roles` بالـJWT، يمنحه **مدير المستأجِر**.
   **لحجم المالك (مُعلَن لا مخفيّ):** المالك يمنح نفسه `season-reviewer` ويقبل إدخالاته — **قبول ذاتيّ مُصرَّح مقبول في هذه المرحلة**
   (أفضل من الممنوع نظريّاً والممارَس فعليّاً)؛ يُسجَّل `accepted_by` بهويّته الحقيقيّة المُصدَّقة (لا مجهول).
3. **المرفق** ✅ — magic bytes + حجم بعد الاستلام + presigned (§4-③).
4. **ميزانيّة المسارات** ✅ — كلّ النقاط على scout-ingest؛ صفر مسار منصّة (حارس route-residual).
5. **ربط الحقل** ✅ — الحقل عبر API الحقول القائم؛ إعادة استخدام مكوّن الرسم؛ الموسم يلتقط `field_id` فقط (لا نسخة هندسة ثانية).

> **`draft_key` (توضيح ملزم):** مفتاح **منع نسخ فقط** (dedup على `tenant+field_id+draft_key`) — **ليس مرجع ثقة، ولا يظهر
> في أيّ قرار قبول** ولا يُكتب في `accepted_by`. القبول يعتمد حصراً على الهويّة المُصدَّقة من الحافّة.
