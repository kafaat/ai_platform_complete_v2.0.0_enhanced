# A7 — طبقة الحدود الإداريّة الموثّقة (مواصفة للمراجعة)

**الحالة:** ⏳ مسودّة للمراجعة (مواصفة → مراجعة → تنفيذ). **الترتيب:** A7 أوّلاً ثم A6 (خريطة SVG للطباعة
تستهلك هذه الطبقة). **المصدر:** الدراسة المقارنة — A7 حدود إداريّة **غائبة**؛ أسماء المحافظات/المديريّات
مُصرَّح بها ذاتيّاً كنصّ حرّ (`log.md:2299`)، لا طبقة هندسة حقيقيّة.

## 1. الواقع اليوم
- **لا جدول حدود بهندسة:** admin1 (محافظات) / admin2 (مديريّات) تظهر كأسماء نصّيّة في
  `weather-service`/`soil-service` لا كـ`geometry` قابلة للعرض/الاحتواء المكانيّ.
- **سابقة الجدول العالميّ:** `weather_automation_locations` **عالميّ عمداً** (موثَّق في
  `tests_v9/test_rls_fk_isolated_tables.py`) — فمفهوم «جدول ليس-لكلّ-مستأجِر» ليس بلا سابقة؛ لكنّ A7
  ستكون **أوّل مرجع مشترك قراءته عامّة لكلّ المستأجرين** (لا بيانات مستأجِر).
- **سابقة A6:** `ST_AsSVG` موجود في `gis-workflow-service` (`bulletin_render.py`/`bulletin_figure.py`) —
  فبنية عرض SVG قائمة تستهلكها A6 لاحقاً.

---

## 2. القرار الحاكم (يجب حسمه) — أوّل جدول مرجع مشترك (shared-reference)

**المأزق (كما رصده المالك):** حدود اليمن الإداريّة **مرجع مشترك** (طبقة خريطة عامّة يقرؤها كلّ المستأجرين)
**لا بيانات مستأجِر**. عزلها بـtenant_id/RLS مثل بقيّة الجداول = خطأ دلاليّ (لا مالك مستأجِر لها). لكنّ فتح
القراءة للجميع يكسر نمط «كلّ جدول معزول بالمستأجِر» — فيجب أن يُعلَن **صراحةً** في العقد.

### التصميم المقترَح
- **`admin_boundaries` جدول مرجع مشترك:** بلا `tenant_id`؛ **قراءة عامّة** لكلّ الأدوار التطبيقيّة؛
  **كتابة مقصورة على دور محمَّل/إداريّ** (لا كتابة مستأجِر أبداً).
- **يُعلَن عالميّاً بنيويّاً:** يُضاف إلى قائمة الجداول-العالميّة-عمداً في `test_rls_fk_isolated_tables.py`
  (نظير `weather_automation_locations`) + `db_ownership.yml` (`readers: [*]` صريح، `writers` = دور المحمِّل فقط).
- **حارس يمنع كتابة المستأجِر:** `GRANT SELECT` لـ`sahool_app`، **بلا** INSERT/UPDATE/DELETE؛ الكتابة عبر
  دور المحمِّل (bootstrap) أو الهجرة نفسها. حارس ساكن يؤكّد أنّ لا مسار تطبيقيّ يكتب `admin_boundaries`.
- **لا RLS-tenant** (لا معنى لها)؛ بدلها **immutability للمرجع** (المرجع لا يُحوَّر عشوائيّاً — يُستبدَل
  بإصدار مصدر جديد عبر الهجرة/المحمِّل، بنسخة موثّقة).

**سؤال المراجعة الأوّل:** هل نعتمد هذا النمط (أوّل shared-reference معلَن، عالميّ، قراءة-عامّة/كتابة-محمِّل)؟

## 3. مرجعيّة المصدر الإلزاميّة (نفس انضباط A5/الحدود/التربة/SIM)
جدول `admin_boundaries` يحمل لكلّ صفّ (أو في جدول provenance مرافق `admin_boundaries_source`):
```
source        TEXT NOT NULL,   -- مثلاً "HDX/OCHA Yemen COD-AB"
version       TEXT NOT NULL,   -- إصدار مجموعة البيانات
retrieved_at  TIMESTAMPTZ NOT NULL,
license       TEXT NOT NULL,   -- مثلاً "CC-BY-IGO 3.0" (يُثبَّت من صفحة HDX)
url           TEXT NOT NULL,   -- رابط HDX المصدر
admin_level   SMALLINT NOT NULL CHECK (admin_level IN (1,2)),
```
**لا حدّ بلا مصدر:** حارس يرفض صفّاً/تحميلاً بلا (source+version+license+url) — نظير «لا معلومة بلا مصدر».

## 4. التحميل (صدق بيئيّ)
- **الهجرة تُنشئ:** الجدول + الفهارس المكانيّة (GIST على geometry) + عقد المرجع المشترك (RLS-off tenant،
  grants) + قيد المصدر. **PostGIS مطلوب** (geometry) — تُطبَّق في بيئة التكامل/الإنتاج.
- **بيانات الحدود نفسها:** ملفّات HDX (GeoJSON/Shapefile، ميغابايتات) **لا تُجلَب/تُلتزَم في هذه البيئة**
  (سياسة الشبكة + تضخّم المستودع). **محمِّل موثَّق** `scripts/load_admin_boundaries.py` (يقرأ ملفّ HDX
  المحلّيّ → يُدرِج بـ`ST_GeomFromGeoJSON` + صفّ المصدر) يُشغّله المشغّل مرّة واحدة. الهجرة/الجدول قابلان
  للاختبار الساكن الآن؛ التحميل الحيّ خطوة مشغّل (كـSIM: البنية الآن، البيانات الحيّة في بيئتها).
- **بديل v1 (للمراجعة):** إدراج **admin1 فقط** (٢٢ محافظة، صغير) كـseed مُلتزَم إن رُخِّص الحجم، وadmin2
  (مديريّات، أكبر) عبر المحمِّل. أم كلاهما عبر المحمِّل؟

## 5. الاستهلاك
- نقطة قراءة `GET /gis/admin-boundaries?level=1|2&bbox=…` (على gis-workflow-service أو platform حسب المالك)
  تعيد GeoJSON للعرض. **A6 يستهلكها** كطبقة سياق في خريطة الطباعة.
- الاحتواء المكانيّ: `ST_Contains(admin.geom, field.centroid)` يربط الحقل بمحافظته/مديريّته (يُغني التقارير).

## 6. الحُرّاس + التحقّق
- **static** `test_admin_boundaries_migration.py`: الجدول + GIST + قيد المصدر + **grants: SELECT لـapp،
  لا INSERT/UPDATE/DELETE** + معلَن عالميّاً في db_ownership + قائمة الجداول-العالميّة.
- **حارس المرجعيّة:** لا صفّ بلا (source/version/license/url)؛ admin_level ∈ {1,2}.
- **حارس منع كتابة المستأجِر:** لا مسار تطبيقيّ يكتب admin_boundaries (grep + grant).
- **حيّ (تكامل، PostGIS):** بعد المحمِّل — `ST_Contains` يربط حقلاً بمحافظته؛ القراءة عامّة عبر مستأجرين.
