# توثيق واجهات SAHOOL (OpenAPI)

توثيق الواجهات على مستويين:

## ١. خريطة المسارات الساكنة (جاهزة الآن — offline)
- **API_MAP.md**: كلّ المسارات (123 مسار، 14 خدمة) مُولّدة بفحص الكود.
- **ROUTE_INVENTORY.json**: نفس البيانات بصيغة JSON للأدوات.
لا تحتاج تشغيل شيء — مُولّدة بفحص `@app.route` ساكناً.

## ٢. مواصفات OpenAPI الكاملة (شغّلها في بيئتك)
خريطة المسارات لا تحوي schemas/parameters/responses التفصيليّة. لتلك،
شغّل في بيئتك (حيث fastapi/pydantic مثبّتتان):
```bash
python3 export_openapi.py
```
يولّد `<service>.openapi.json` لكلّ خدمة عبر `app.openapi()` (بلا uvicorn)،
+ `INDEX.md` موحّد. الناتج spec قياسي تستخدمه:
- Swagger UI / Redoc (عرض تفاعلي)
- توليد عملاء (openapi-generator)
- اختبارات العقود (contract testing)
- مراجعة الأمان (تدقيق المسارات المكشوفة)

## لماذا التقسيم؟
الخريطة الساكنة تعطي قيمة فوريّة بلا تثبيت. المواصفات الكاملة تحتاج استيراد
الخدمات فعليّاً (حزم ثقيلة: rasterio/redis...) — أنسب لبيئتك.
