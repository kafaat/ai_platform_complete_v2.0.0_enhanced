# جعل `farm_id` إلزاميّاً — دليل النشر (Rollout Runbook)

بند «`farm_id` إلزاميّ» من `POST_DEPLOYMENT_ROADMAP.md`. هذا **عمل نافذة نشر** لا
تغيير يُطبَّق في الكود الآن — لسببين جوهريّين يجعلان التنفيذ الأعمى في الصندوق
المعزول غير مسؤول:

1. **Backfill عابر المستأجرين تحت RLS:** `farms`/`fields` عليهما `FORCE ROW LEVEL
   SECURITY`؛ هجرة عاديّة لا تستطيع الكتابة عبر المستأجرين إلّا كمالك/superuser
   يتجاوز RLS. لذا الـbackfill سكربت نشر يدويّ (`scripts/farm_id_backfill.sql`)
   **خارج MANIFEST** (لا يُطبَّق تلقائيّاً).
2. **تغيير سلوكيّ كاسر:** جعل `farm_id` إلزاميّاً يرفض إنشاء حقل بلا مزرعة —
   يتطلّب تنسيقاً مع الواجهة (إنشاء مزرعة أوّلاً؛ منطق `canCreateFarm` جاهز) ولا
   يُتحقَّق منه إلّا بقاعدة حيّة + عملاء محدَّثين.

## التسلسل الآمن (نافذة الصيانة)
1. **نسخة احتياطيّة:** `scripts/backup_postgres.sh`.
2. **Backfill:** شغّل `scripts/farm_id_backfill.sql` **كمالك القاعدة/superuser**
   (المرحلتان ١–٢: مزرعة افتراضيّة/مستأجِر + إسناد الحقول اليتيمة). idempotent.
3. **تحقّق:** `SELECT count(*) FROM fields WHERE farm_id IS NULL;` ⇒ يجب أن يكون **0**.
4. **نشر تغيير الواجهة/الـAPI:** اجعل `farm_id` إلزاميّاً في إنشاء الحقل (انظر
   «تغيير الكود» أدناه) + إلزام الواجهة بإنشاء مزرعة أوّلاً.
5. **القيد القاعديّ:** شغّل المرحلة ٣ من السكربت (`ADD CONSTRAINT … NOT VALID`
   ثمّ `VALIDATE CONSTRAINT`). يفشل `VALIDATE` لو بقي صفّ NULL ⇒ ارجع للخطوة ٢.

## تغيير الكود (يُطبَّق وقت النشر، سطر واحد)
في `api/main.py` نقطة إنشاء الحقل: `FieldCreateRequest.farm_id` من
`str | None` إلى **إلزاميّ** (`str`، `min_length=1`)، مع إبقاء التحقّق القائم أنّ
المزرعة تخصّ المستأجِر (404). بقيّة التحقّق (وجود المزرعة) موجودة فعلاً.

## التراجع (Rollback)
- قبل الخطوة ٥ (القيد): التراجع = إعادة `farm_id` اختياريّاً في الـAPI (لا تغيير
  قاعدة لازم — الحقول مُسندة لمزرعة افتراضيّة، وهو وضع صالح).
- بعد القيد: `ALTER TABLE fields DROP CONSTRAINT chk_fields_farm_required;`.

## لماذا artifact لا تنفيذ الآن؟
الـbackfill يحتاج بيانات حيّة + سياق RLS، والقيد كاسر — كلاهما يُتحقَّق منه على
قاعدة حيّة فقط. تقديم سكربت مُراجَع + runbook هو **الإكمال المسؤول** لبند نافذة
النشر، بدل شحن DDL كاسر/غير مُتحقَّق منه في الصندوق المعزول.
