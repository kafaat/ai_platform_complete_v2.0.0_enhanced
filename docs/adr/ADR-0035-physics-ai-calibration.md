# ADR-0035: PHYSICS-AI-CALIBRATION-01 — معايرة المحرّك الفيزيائيّ بالذكاء الاصطناعيّ

- **الحالة**: معتمد (Ratified) — قرار معماريّ مرجعيّ
- **تاريخ الاعتماد**: 2026-07
- **نطاق القرار**: معايرة نموذج المياه/المحاصيل الفيزيائيّ بمساعدة الذكاء الاصطناعيّ، وضوابط أهليّة الموسم، وسجلّ المعايرة، وسجلّ النماذج
- **قاعدة حاكمة**: هذه الوثيقة قرار مرجعيّ للأرشفة — **لا تُحوَّل إلى backlog تنفيذيّ قبل تحقّق `build_unlock` حرفيًّا** (انظر «تسلسل فكّ الحجب»).

> التزامًا باتّفاقيّة الترقيم المعتمدة في هذا المجلّد — النصّ بلا أيّ تغيير تحريريّ.

## حكم المراجعة النهائيّ

الحكم النهائيّ متماسك ومعتمد كما هو. لا توجد فجوة معماريّة ظاهرة أو تعارض بين بنود التحليل (A1–A6) وبنود الاختبار (T-A–T-C).

## الحالة التشغيليّة المعتمدة

ADR معتمد
→ **البناء محجوب**
→ تُجمَع الدفاتر والأدلة الحقيقيّة
→ يُستكمل SIM-GOLDEN
→ يُعاد البرهان السلبيّ على المستودع
→ يُفتح نطاق معايرة محدَّد فقط

## الضوابط المحسومة

1. `season_calibration_eligibility` **بوّابة أهليّة، وليست حلقة معايرة**.
2. **الموسمان شرط أدلّة لنطاق محدَّد**، لا تصريحًا عامًّا لكلّ المحاصيل والمناطق.
3. **المحرّك الفيزيائيّ يُعايَر أوّلًا**، ثمّ residual محدود ومحكوم.
4. **الـLLM يفسّر ويصوغ مرشّحًا؛ لا يحسب ولا يغيّر معاملات.**
5. **لا تحديث إنتاجيّ مباشر من النتائج الحقليّة.**
6. أيّ حالة **OOD** تعطّل التصحيح الذكيّ وتعود إلى physics-only أو المراجعة البشريّة.
7. **Calibration Ledger وModel Registry لهما ملكيّتان منفصلتان** بوضوح.
8. **Rquefts يبقى Oracle خارجيًّا فقط.**
9. **لا يبدأ البناء** قبل اكتمال دفتر المياه وSIM-GOLDEN والمواسم المقبولة.

## تسلسل فكّ الحجب (build_unlock)

لا يُفتح التنفيذ إلا بعد تحقّق كلّ ما يلي حرفيًّا:

- [ ] اكتمال دفتر المياه (Water Ledger) بالأدلّة الحقيقيّة
- [ ] اكتمال SIM-GOLDEN
- [ ] المواسم المقبولة عبر بوّابة الأهليّة `season_calibration_eligibility`
- [ ] إعادة البرهان السلبيّ على المستودع
