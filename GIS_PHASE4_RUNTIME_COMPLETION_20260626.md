# SAHOOL GIS Phase 4 Runtime Completion — 2026-06-26

## ما تم تحويله من Facade إلى Runtime قابل للتشغيل

### 1) DB-backed STAC + COG Registry
- Added `shared/gis/cloud_native_runtime.py` for converting `raster_registry` rows into STAC Items/Collections.
- Added `POST /api/v1/gis/cloud-native/cog-registry` to register COG products with quality scoring.
- Added `GET /api/v1/gis/cloud-native/stac/search` and collection endpoint.

### 2) MosaicJSON فعلي من السجلات
- Added `GET /api/v1/gis/cloud-native/mosaicjson` built from `raster_registry` rows.
- Groups actual COG URLs by scene/raster id and returns MosaicJSON 0.0.3.

### 3) TiTiler Service Scaffold
- Added `services/raster-tiler-service/Dockerfile` using `titiler.application`.
- Added service entry to main compose variants.
- `TileJSON` generated by platform points to `TITILER_BASE_URL` or `/tiler`.

### 4) GeoParquet Export Adapter
- Added `/api/v1/gis/cloud-native/geoparquet/export`.
- Uses GeoPandas/PyArrow when present, with deterministic JSONL fallback for CI/dev where optional GIS dependencies are unavailable.

### 5) Editing Sessions + Geometry Locks API
- Added upsert editing sessions endpoint.
- Added acquire/release geometry lock endpoints with TTL and conflict protection.
- Fixed migration field_id types to match existing SAHOOL `fields.field_id` string IDs.

### 6) RLS Compatibility Fix
- Updated v97 policies to use `app.current_tenant`, consistent with existing tenant_connection/RLS conventions.
